01ALM 模型全景：三端结构与建模流程 ★★教

一个完整的保险公司 ALM 模型由三端构成，数据在端与端之间流动形成闭环：

端输入核心引擎输出
负债端保单数据 / 精算假设（死亡率、退保率、费用、分红）负债现金流预测模型（含选择权行为模型）负债现金流时间序列、准备金、久期 / 凸性、VIF
资产端持仓明细（券、非标、股权、衍生品）+ 市场数据资产现金流与重定价模型、估值引擎资产现金流、再投资需求、市值 / 账面值、久期
策略端两端的缺口信号 + 约束（监管 / 账户 / 风险偏好）优化器（缺口最小化 / 收益最大化 / 风险预算）SAA 方案、再平衡指令、对冲方案

建模七步流程

① 明确目标与约束 —— 监管约束（量化评估指标、偿付能力）+ 公司约束（风险偏好、账户隔离、流动性）。
② 负债建模 —— 按产品分组预测现金流；关键难点是投保人行为假设（退保、部分领取、万能结算利率弹性）。
③ 资产建模 —— 现金流映射（固定收益逐笔、非标摊余、权益类市值漂移）；含违约与提前偿还模块。
④ 情景生成 —— 确定性情景（监管六情景）+ 随机情景（利率随机模型：单因子 / 双因子 Hull-White、CIR、LIBOR 市场模型）。
⑤ 联动计算 —— 每个情景下资产 × 负债现金流轧差 → 缺口序列 / 净资产分布。
⑥ 优化与回测 —— 用历史数据回测模型偏差（经验分析调整行为假设），用优化器搜索满足约束的最优配置。
⑦ 监控与再平衡 —— 指标监控 → 触发再平衡 → 回到第 ① 步，形成年度循环。
折叠 · 模型分类谱系与选型逻辑

按确定性程度：确定性模型（deterministic，单一利率路径，用于监管报送与基础报表）→ 情景模型（scenario-based，有限个规定情景，用于压力测试）→ 随机模型（stochastic，数千条蒙特卡洛路径，用于经济资本与尾部风险）。

按建模颗粒度：因子模型（久期 / 凸性 / PV01 快速近似，日常监控用）vs 现金流模型（逐保单或模型点 model point，年度评估用）。实务中两层并存：日频用因子层看方向，季度 / 年度用现金流层定方案——这就是 CH.04 讲的「久期匹配是第一道防线、现金流匹配是第二道防线」的技术实现。

选型三问：用途是什么（监管 / 内控 / 定价）？数据支持到什么颗粒度？计算资源允许跑多少条路径？——考试论述「如何搭建 ALM 模型」时按这三问展开即是框架分。

02负债端：四类准备金口径与三差分析 ★★★教规题

同一家公司同一时点，负债可以按四个不同口径计量——这是理解偿付能力、会计利润与税务「三张皮」的钥匙，也是 2026 真题 Excel 1 成本收益匹配题的底层语言：

口径依据特征用途
法定准备金监管规定（偿二代 + 精算规定）审慎原则：不利假设、不许认可未来投资收益的超额部分偿付能力报告、监管考核
会计准备金企业会计准则（新保险合同准则 / IFRS17）最佳估计 + 风险调整 + CSM 摊销；折现率盯市财务报表、对外披露
税务准备金税法一般在法定或会计口径上做调整（可抵扣限额）所得税计算
内含价值口径负债EV 评估标准最佳估计假设 + 市场一致折现；扣除要求资本对应负债EV / VNB 评估

四口径并存的后果：同一保单在四个体系里的「利润」确认节奏不同——法定口径最保守（利润前置空间小）、EV 口径把未来利润折现（VIF）、会计口径按 CSM 摊销（利润后置且平滑）。考试问「为什么偿付能力充足但报表亏损」（或反之），答案就在口径差异 + 投资端会计分类的联动里。

三差分析：负债端经营语言的公分母

利差（实际投资收益率 − 准备金评估假设利率）、死差（实际赔付 / 给付 vs 假设）、费差（实际费用 vs 假设费用）——加上退保差与利源分析，构成「三差（五差）」体系。ALM 视角下最重要的是利差，而利差的分母正是准备金口径：法定口径利差 ≈ 投资收益率 − 定价利率（刚性）；EV 口径利差 ≈ 投资收益率 − 资产份额累积利率（可调）。2026 真题 Excel 1 的「平均负债成本 K」本质就是法定 / 会计口径的负债成本率，与 G（投资收益率）相减即利差 M——负利差就是利差损的当代表现。

03资产端估值：三类方法与会计分类联动 ★★★教规

主库此前只写了负债怎么估，这一节补资产怎么估——ALM 的资产端语言。估值方法按信息来源分三类：

估值方法适用资产技术要点风险点
① 摊余成本法持有至到期债券、贷款、非标现金流折现按实际利率法摊销利息利率上行时账面值高估（隐藏浮亏）；违约减值
② 市场 / 可观察价格法上市股票、交易所债券、公募基金收盘价 / 中债估值 / 中证估值流动性差的券估值失真；停牌股僵死
③ 模型估值法非上市股权、不动产、衍生品、私募现金流折现（DCF）、最近融资价格法、市场乘数法（P/E、P/B、Cap Rate）、期权定价模型假设敏感、估值频率低（季度 / 年度）、顺周期波动

与 IFRS9 三分类的联动（资产端会计语言）

IFRS9 分类计量波动去向保险资金典型持仓
AC 摊余成本摊余成本 + 预期信用损失（ECL）不进损益（减值除外）持有至到期利率债、高等级信用债
FVOCI 以公允价值计且变动进其他综合收益公允价值公允价值变动进 OCI，处置时不转损益（债）/ 转损益（股）以收取现金流兼出售的债券、部分战略持股
FVTPL 公允价值计且变动进损益公允价值直接进当期损益交易性债券、股票、基金、衍生品、不满足 SPPI 的资产
折叠 · ALM 如何利用会计分类「降波动」——2026 真题简 8 的进阶版答案

机制：负债端在 IFRS17 下若选择「风险调整与未来现金流不计提纾困特征、折现率变动进 OCI」的组合，则资产端配 FVOCI 债券，使折现率变动对负债的影响与利率变动对 FVOCI 资产的影响同进 OCI、方向相反、自然对冲——损益表只留承保与费用科目，报表波动大幅下降。

约束：① SPPI 测试（本金 + 利息特征）淘汰了含权债、结构化产品；② 指定 FVOCI 的权益工具不可逆转、处置不转损益；③ 摊余成本类资产需通过业务模式测试（持有收取现金流）。过度摊余成本化的代价：利率上行期的浮亏藏在账面值里，净资产失真——这就是监管 2023 年后反复提示「长债利率风险」时要求保险机构加强 AC 类资产利率风险评估的原因。

与偿二代的关系：会计分类不影响认可价值（认可口径按监管规则计量），但影响净资产波动路径，进而影响实际资本中「核心一级 = 净资产」的季节性波动。答题时写出「会计分类 → OCI 对冲 → 实际资本波动下降」这条传导链，就是满分结构。

04利率与再投资：曲线假设的三个层次 ★★教规

ALM 模型里所有折现与再投资都挂在一条利率曲线上，但「一条曲线」其实有三个层次，混用层次是实务建模最常见的错误：

层次含义典型来源用在模型哪里
即期曲线（市场曲线）当前时点各期限零息收益率国债收益率曲线、750 日移动平均（偿二代 / 准备金）存量资产负债的折现
远期 / 情景曲线未来各时点的预期或压力曲线监管六情景（专章 B）、随机利率模型生成未来现金流的再投资定价与压力测试
终极利率（Ultimate）超长期限锁定的收敛利率规则第 4 号 40 年以上变动为 0；EV 标准终极利率假设超长久期负债（终身寿、年金）的尾部折现

再投资假设的三种流派：① 现期收益率外推（简单但失真）；② 曲线远期利率（无套利但长期偏高——「远期利率不是预期」的经典陷阱）；③ 情景 / 随机模拟（监管成本收益压力情景即此流派：情景二长期低利率就是把再投资收益率按期限系统性下调 73%~24%）。考试答「情景二与情景三的差别」，本质就是再投资假设的下调方式不同：前者缓降（长期低利率），后者跳升（+100bps × 2 年）。

05再平衡机制：阈值、频率与触发器设计 ★★教题

SAA 定的是「航道」，再平衡解决「偏航后何时修正」。三种机制各有代价：

机制规则优点缺点
定期再平衡固定频率（季度 / 年度）调回目标权重纪律性强、可预期对区间内漂移不敏感；市场极端时反应慢
阈值再平衡资产类别权重偏离目标 ±X% 或久期缺口超 ±N 年即触发与风险指标挂钩、响应及时波动市场里频繁触发 → 交易成本与税收摩擦
事件触发再平衡重大事件（大额保费流入 / 集中退保 / 偿付能力跌破内控线 / 监管新规）即时评估覆盖模型盲区依赖人工判断，需明确事件清单与授权

与监管指标的衔接：实务上阈值常直接锚定量化评估指标——久期缺口内控线 ±2 年（监管满分线）、成本收益匹配口径利差 M ≥ 0、流动性比例 ≥ 5%。这样一旦指标逼近扣分区，再平衡自动前置。考试答「如何执行 SAA」（2016/2026 简答反复出现），三层机制 + 锚定监管指标就是完整框架。

考点回链：CH.04 §4.4 SAA/TAA · 专章 B 久期缺口评分档

06IFRS17 下的 ALM：CSM 联动与背对背对冲 ★★规

新保险合同准则不只改变披露，还改变了 ALM 的管理目标函数——从「管理净资产」部分转向「管理 CSM 摊销节奏 + OCI 波动」：

  • 计量单元与分组：按盈利性分组（亏损组立即确认 P&L、无显著可能性亏损组单独处理），ALM 需按组别匹配资产；
  • CSM 吸收机制：与非金融假设变动相关的未来现金流变化调整 CSM（摊销节奏改变）而非当期损益——负债端有了「缓冲垫」，资产端 FVOCI 对冲与之配合；
  • 背对背（back-to-back）对冲：对分红险等 participating 合同，若持有底层资产公允价值变动与负债分红调整基本同步，损益接近零波动——ALM 从「久期匹配」升级为「盈余分配机制匹配」；
  • VFA 变动收费法：分红账户负债与底层资产回报挂钩，CSM 随资产回报浮动——直接改变「利差」的定义：从固定假设利差变为「实际资产回报 − 分红支出」的余额。
折叠 · IFRS17 × 偿二代 × EV 三体系对照表（考纲外大杀器）
维度偿二代IFRS17 / 新准则EV 评估标准
负债计量法定认可口径（审慎）履约现金流（最佳估计 + 风险调整）+ CSM最佳估计 + 市场一致折现
折现率750 日国债 + 综合溢价（三段）盯市曲线（OCI 指定或损益）与资产一致的税后投资收益率 / 市场曲线
未来利润不认可（审慎）CSM 摊销释放VIF 折现确认
波动偏好越稳越好（监管视角）中性（反映经济实质）评估日时点值
与 ALM 的接口量化评估 30/40/30OCI 对冲 / 背对背 / VFA投资假设敏感性 ±50bps → ±20%

论述题若问「三套体系下资产负债管理目标是否一致」：目标一致（都要求资产覆盖负债的期限内与价值上匹配），但度量语言不同——偿二代讲缺口与资本占用、新准则讲 CSM 摊销与 OCI 波动、EV 讲折现值与假设敏感性。成熟公司的 ALM 治理是在一套模型上同时输出三套口径的报表（「一次建模、三口径输出」）。

07五大应用场景与考试视角 ★★★教题

ALM 模型的输出最终落在五个管理场景——这也是论述题「资产负债管理在公司经营中的作用」的展开骨架：

场景ALM 提供什么决策示例
① 产品开发负债特性画像（久期、保证成本、退保权价值）预定利率上限设定、新业务利差敏感性、分红演示利率
② 投资策略SAA 优化、久期 / 现金流匹配方案、再平衡阈值增配 30 年国债对冲年金、非标额度控制
③ 资本管理利率冲击下实际资本变动、资本工具选择发行资本补充债补综合充足率（2026 Excel 3）
④ 风险管理压力测试 / 情景分析、尾部风险度量情景三跳升预案、退保潮流动性预案
⑤ 绩效考核三差归因、EV 营运利润、投资超额收益分解长周期考核（3/5 年权重 50%/20%）、VNB率考核

核心问题自测

四类准备金口径的差异根源是什么？

目标函数不同：法定口径服务监管审慎（不利假设）、会计口径服务投资者信息（最佳估计 + 盯市）、税务口径服务税基确定、EV 口径服务股东价值（市场一致折现）。差异主要体现在折现率、未来利润认可与审慎边际三处。

资产估值三方法分别的风险点？

摊余成本法：利率上行隐藏浮亏、违约减值滞后；市场法：低流动性券估值失真；模型法：假设敏感、估值频率低且顺周期。IFRS9 通过 SPPI 与业务模式测试决定分类，分类再决定波动进损益还是 OCI。

再平衡三机制的触发逻辑与代价？

定期（纪律强但反应慢）、阈值（盯风险指标但频繁触发有交易成本）、事件触发（覆盖盲区但依赖人工）。实务以阈值为主、定期为辅、事件清单兜底，阈值常锚定监管扣分区（如久期缺口 ±2 年）。

IFRS17 如何改变 ALM 的目标函数？

从单纯管理净资产转向同时管理 CSM 摊销节奏与 OCI 波动：非金融假设变动进 CSM 缓冲；VFA / 背对背安排使负债与资产回报联动；资产端 FVOCI 与负债折现率 OCI 指定形成自然对冲——「一次建模、三口径输出」成为治理标配。

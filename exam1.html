模拟卷（一）筑基卷

满分 100 分　·　多选题每题 3 分（多选 / 错选不得分，少选得 1 分）　·　简答题共 70 分
本卷为自编模拟题，题风对标 2013/2014 历年多选 + 简答结构

A多选题（每题 3 分，共 30 分）

选项已按 A~E 标注（仿真卷面）；参考答案与解析默认折叠——先做完再展开对照。

1关于资产负债管理（ALM）的定义与目标，下列说法正确的有：
  • ALM 是通过协调资产端与负债端决策，实现公司经营目标、同时控制风险的技术与制度安排
  • ALM 的目标可分为公司层面、产品层面和日常经营层面三个层次
  • ALM 的首要目标是最大化投资收益率
  • ALM 是一种持续、动态的管理过程，而非一次性的静态匹配
  • ALM 只适用于寿险公司，非寿险公司不需要
解析

C 错——收益率单目标优化恰恰是 ALM 要纠正的倾向（负债冲规模、资产冲收益的错配根源，专章 D）；E 错——财险公司同样有成本收益与流动性匹配要求，2026 征求意见稿已明确覆盖。答案：ABD

2保险公司实施 ALM 的主要途径包括：
  • 产品管理（定价、产品结构设计）
  • 资产配置管理（SAA / TAA）
  • 再保险安排
  • 动态财务分析（DFA）与情景 / 压力测试
  • 更换审计师与精算师
解析

四大途径 = 产品管理、资产配置、再保险、DFA（CH.01，2013 真题第 16 题原考点）。答案：ABCD

3关于 ALM 组织架构中各主体的职责，下列说法正确的有：
  • 董事会对资产负债管理承担最终责任，审定 ALM 总体目标与战略
  • 资产负债管理委员会（高管层下设的执行委员会）负责日常管理与沟通协调
  • 精算部只负责准备金评估，不参与资产负债管理
  • 牵头部门担任资产负债管理秘书处，组织跨部门协调
  • 总资产小于 1000 亿元的财险公司可以不设资产负债管理委员会
解析

C 错——精算部是负债端假设与现金流预测的核心部门（历年真题 2013·24、2014·24 反复考职责分工）；E 是 32 号办法原文。答案：ABDE

4关于久期，下列说法正确的有：
  • Macaulay 久期是现金流支付时间的现值加权平均
  • 修正久期 = Macaulay 久期 / (1 + y)，刻画价格对收益率的近似敏感性
  • 零息债券的久期小于同期限的票息债券
  • 久期相同的情况下，凸性大的债券在利率大幅变动时价值损失更小
  • 含权债券（如可赎回债）更适合用有效久期而非修正久期度量利率风险
解析

C 错——零息债久期等于期限本身，是同期限债券中最长的（2014 真题第 5 题考点：同久期下零息债凸性更大）。答案：ABDE

5Redington 免疫的经典条件包括：
  • 资产现值 = 负债现值
  • 资产久期 = 负债久期
  • 资产凸性小于负债凸性
  • 资产凸性大于负债凸性
  • 资产现金流必须与负债现金流逐期完全相等
解析

免疫三条件：现值相等 + 久期相等 + 资产凸性 > 负债凸性（利率双向变动时净资产均不减少）；E 是现金流匹配而非免疫的要求——免疫只盯住价值层面，是近似保护。答案：ABD

6下列属于寿险公司负债特性的是：
  • 长期性与利率敏感性
  • 含有内嵌选择权（退保、保单贷款、红利选择权等）
  • 万能险负债成本具有"上不封顶、下有保底"的浮动结算特征
  • 负债期限普遍短于资产期限
  • 分红险负债对投资收益率假设具有内在一致性要求
解析

D 与中国实际正好相反——负债久期长于资产久期（错配缺口约 7 年，专章 D）。答案：ABCE

7关于现金流匹配，下列说法正确的有：
  • 现金流匹配要求资产现金流的时间分布与负债现金流的时间分布相吻合
  • 非寿险公司由于赔付的随机性与短周期性，难以实现严格的现金流匹配
  • 再保险分出业务会加大现金流匹配的难度，因此不应使用
  • 监管现金流测试采用三级检验体系（累计现金 → 高流动性资产变现 → 中低流动性资产变现）
  • 中低流动性资产变现后累计现金流仍至少一期为负的，ALM 量化评估整体记 0 分
解析

C 错——再保险是 ALM 四大途径之一，虽然引入交易对手现金流，但能分散承保风险、改善偿付能力（CH.04）。D、E 为规则第 4 号一票否决条款。答案：ABDE

8偿二代二期下，保险公司偿付能力达标须同时满足：
  • 核心偿付能力充足率 ≥ 50%
  • 综合偿付能力充足率 ≥ 100%
  • 风险综合评级不低于 B 类
  • 核心偿付能力充足率 ≥ 100%
  • 流动性比例 ≥ 5%
解析

达标三条件：核心 ≥50% + 综合 ≥100% + 风险综合评级 ≥B 类（CH.02）。流动性比例 ≥5% 是 ALM 量化评估的指标，不是偿付能力达标条件——两个 5% 别混淆。答案：ABC

9关于内含价值（EV）的构成，下列说法正确的有：
  • EV = 自由盈余 + 要求资本 + 有效业务价值 − 要求资本成本
  • EV 不包括未来新业务产生的价值
  • 新业务价值 VNB 按保单到期时点计值
  • 要求资本是受法律法规和公司内部管理限制、不能分配给股东的金额
  • 金融选择权和保证通常提高 VIF
解析

C 错——VNB 按签单时点计值；E 错——金融选择权和保证降低 VIF（专章 C §VIF 六注意）。答案：ABD

10关于久期缺口与利率风险，下列说法正确的有：
  • 久期缺口 = D_A − D_L × V_L / V_A
  • 当久期缺口为负（负债久期相对更长）时，利率下行使净资产减少
  • 利率下降时，资产与负债价值均上升，但负债上升更多导致净资产受损
  • 久期缺口为零意味着任何利率变动下净资产完全不变
  • 久期缺口管理是传统险账户降低报表波动的重要手段
解析

D 错——久期匹配只是免疫的一阶近似，大额或非平行变动下仍需凸性与关键期限（DV10）管理。可用 专章 A 久期缺口演算器 验证 A、B、C。答案：ABCE

B简答题（共 70 分）

一（12 分）简述保险公司资产负债管理的六步流程，并说明每一步的核心产出。
参考答案
① 负债特性分析核心产出：负债现金流预测、久期 / 凸性 / 关键期限分布、负债成本（预定利率 / 结算利率）画像。
② 设定 ALM 目标与风险容忍度核心产出：公司 / 产品 / 日常三层次目标与量化限额（久期缺口区间、利差底线、流动性比例）。
③ 制定资产配置策略（SAA）核心产出：分账户大类资产目标比例与再平衡规则。
④ 实施与产品设计 / 再保安排联动核心产出：定价假设与投资假设一致性校验、再保方案。
⑤ 监控与评估核心产出：量化评估评分（30/40/30）、久期缺口 / 利差 / 现金流三级检验的定期报告。
⑥ 调整与反馈核心产出：TAA 战术调整、假设重估、SAA 年度滚动修订。

考点回链：CH.01 六步流程

二（14 分）万能险的负债特征有哪些方面？这些特征对资产端配置提出了什么要求？（2013·18、2017·8 原型）
参考答案

负债特征五方面：① 最低保证利率——结算利率下有保底（刚性成本底线，情景三下 +100bps 上浮）；② 浮动结算机制——"上不封顶、下有保底"，公布结算利率逐月 / 逐季可调，但有市场预期粘性（下调受阻于客户流失）；③ 高流动性 / 退保选择权——账户价值可随时支取，退保弹性大，利率与结算利差驱动客户行为（追涨杀跌）；④ 缴费灵活——趸交 / 追加 / 部分领取由客户掌握，现金流规模不确定；⑤ 账户独立管理——通常设独立账户，资产组合可含较高权益比例。

对资产端的要求：① 资产久期不宜过长（负债久期相对短、退保随时发生）——历史上万能账户久期常在 5~7 年；② 保持相当比例高流动性资产以应对退保与部分领取；③ 收益基准盯住结算利率预期，需在"保底成本 + 客户预期"之上争取利差；④ 权益敞口受独立账户口径与偿付能力资本占用约束（权益因子 0.35/0.30）；⑤ 用情景测试刻画结算利率下调粘性下的利差损风险。

考点回链：CH.01 万能险折叠卡 · 专章 D 36 个月规则

三（14 分）某负债的现金流如下：第 1 年末 50、第 2 年末 50、第 3 年末 500（单位：万元）。市场利率为 3%。
（1）计算该负债的现值与 Macaulay 久期；（2）若市场利率上升 50bps，用久期近似估算负债价值的变化；（3）说明久期近似法的局限。

四（15 分）从资产负债管理角度，分析我国寿险公司"资产期限短于负债期限"这一错配格局的成因与风险，并提出改善措施。（2009 前·11 原型升级）
参考答案

成因三方面：① 负债端——终身寿险、年金等长负债久期天然长（负债久期常 10 年以上）；② 资产端——长期高收益资产供给不足：超长期利率债规模有限、优质非标逐步到期且剩余期限收窄、权益资产虽长久期但波动大；③ 经营端——规模导向的销售策略偏好短期缴费产品快速做大资产，投资考核短周期化削弱拉长久期的动力（专章 D 四大成因）。

风险三方面：① 再投资风险——资产先于负债到期，新钱再投资收益率趋势性下行 → 利差损（缺口约 7 年）；② 利率下行净资产损失——负债现值增幅超过资产（可用久期缺口演算器演示：利率 −50bp、D_A 6 / D_L 10 时净资产显著缩水）；③ 报表与偿付能力波动——折现率下移推高认可负债、侵蚀实际资本。

措施四条：① 增配超长期国债 / 地方债拉长资产久期，向免疫条件靠拢；② 负债端控制长久期高保证产品的新增、推动预定利率与市场利率联动；③ 用利率互换 / 国债期货等衍生品对冲剩余缺口；④ 治理上推行长周期考核（3 年 / 5 年权重 50% / 20%），把久期缺口纳入 ALM 量化评估与考核。

考点回链：专章 D · CH.04 久期缺口

五（15 分）简述内含价值报告的信息披露要求与 EV 使用注意事项；并说明"新业务"与"经验偏差"的边界如何界定。
参考答案

披露要求（标准第五十条）：上市公司应根据相关法律法规公开披露经外部审阅的内含价值报告；披露内容至少包括：主要评估方法和假设、计算结果、相关分析、敏感性测试。重要性上限：近似方法处理差异不超过 EV（或 VNB）总额的 5% 与 1000 万元孰大，方法有差异须明确说明。

使用注意事项（第九条）：EV 不是衡量公司价值的唯一方法；EV 受经济环境和经营环境影响（利率下行时 EV 下调），使用者应充分理解 EV 的变化及原因；EV 是时点值，需借助 EV 桥判断质量。

边界界定（第十八条）：应作为经验偏差而非新业务处理的三种情形——① 与有效合同预期保费的偏差；② 与趸交累加型合同预期续期保费的偏差；③ 有效业务预期保费的重新定价。判断原则：预期之内的变化早已在模型里，实际与预期的差是偏差；全新签发并核保录入的新保单才是新业务。VNB 按签单时点计值、含 CoC、含预期续保与合同变动价值。

考点回链：专章 C §假设与披露、§VNB 三原则

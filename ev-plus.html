01中国 EV 体系建设史：三个文件与两次换轨 ★★规

时点文件里程碑意义
2005《人身保险内含价值报告编制指引》中国 EV 制度起点：首次统一 EV 报告口径，强制披露 EV 与 VNB
2010《人身保险内含价值评估标准》（试行）从「报告指引」升级为「评估标准」：确立四要素框架、经验分析要求、独立签署制度
2016《精算实践标准：人身保险内含价值评估标准》（现行）与偿二代一期全面衔接：RC 采用最低资本口径、认可资产口径统一、披露与重要性门槛细化

两次换轨：① 偿二代换轨（2016）——EV 的 RC 从「法定资本要求」改为「最低资本 MC」，使 EV 与偿付能力报告共享一套资本模型，EV 对市场风险的敏感度显著上升；② IFRS17 换轨（2023 起执行）——新准则的 CSM 摊销逻辑与 EV 的 VIF 折现逻辑并存，市场上出现「双轨披露」：报表利润用 CSM、股东价值用 EV，两套语言的调节表成为投资者沟通新课题。若内含价值标准再次修订（行业已启动研究），RC 口径与折现率规则可能再度调整——这正是首页制度地图标注「过期预警」的原因。

02评估价值体系：EV + VNB 乘数 + 商誉 ★★★教题

EV 只度量存量业务；一家持续经营的公司值多少钱，还要加上未来新业务的价值与控制权溢价：

评估价值 AV = 内含价值 EV + 未来新业务价值 GNB（Goodwill-Novas，按乘数或逐单预测）
收购价 ≈ AV + 控制权溢价 − 少数股东调整；商誉 = 收购价 − 可辨认净资产公允价值

未来新业务价值的两种算法

方法操作适用风险点
乘数法GNB = 当期 VNB（年化）× 乘数（如 5~10 倍）市场速算、估值参照乘数主观；增长与贴现假设隐藏在倍数里
逐单 / 预测法按业务计划逐年预测 VNB 并按 RDR（或 WACC）折现正式评估、并购定价依赖业务计划可信度；假设弹性大

乘数与 P/EV 的换算直觉：市场常用 P/EV（股价 ÷ 每股 EV）给上市险企估值——P/EV < 1 意味着市场认为 EV 里的假设（投资收益率、退保率）偏乐观，或未来新业务价值为负增长。为什么 EV ≠ 收购价（论述题经典）：① EV 不含未来新业务；② 收购产生商誉与整合成本；③ 控制权溢价；④ 假设差异（收购方用自己的 RDR 重估 VIF）；⑤ 税务与资本摩擦（收购方偿付能力约束）。——专章 C §7 讲了骨架，这里给出完整五条。

03EV 变动分析：一行公式的完整展开 ★★★教

《内含价值变动分析的原理》的核心：期末 EV 与期初 EV 之间不是「黑箱」，而是可以被完整分解的恒等式：

EV期末 = EV期初 + VNB + EV期望回报 + 假设变化的影响 + 经验偏差 + 投资回报差异 + 模型与参数调整 + 资本变动（分红/注资/资本工具发行）± 其他

其中最重要的区分是转移项与非转移项：

类别包含性质管理含义
转移项（预期内）VNB、EV 期望回报（期初 EV 按假设「滚利息」——VIF 折现期缩短一年 + 资产回报）假设成立时就该发生的变动不创造超额价值；考核基线
非转移项（未预期）经验偏差（死亡 / 退保 / 费用 / 赔付实际 vs 假设）、假设变化、投资回报差异、模型调整假设不成立产生的差异真正的价值创造 / 毁灭来源；管理抓手
折叠 · 逐项拆解：EV 桥 19 项与本公式的对应

标准附件 2 的 19 项分析要点按四大类归位到上式：新业务的预期影响（VNB + 假设在新业务上的影响）→ VNB 项；经营经验的差异（死亡、伤残、疾病、退保、费用等实际与假设差异）→ 经验偏差项；假设变化的影响（经济假设：投资收益、费用通胀、税率；非经济假设：死亡率、退保率、承保规则）→ 假设变化项；投资回报的差异（实际投资收益 vs 假设收益）→ 投资回报差异项——2016 标准特别将其单列，因为它通常是最大波动项（对应敏感性分析中投资收益率 ±50bps → EV ±20% 的统治级地位）。

一个必懂细节：期初 VIF 在一年后应按 RDR「展开」（roll-forward）——不仅贴现期缩短，还要加上要求资本释放与持有成本变化。若公司实际投资收益率恰好等于假设、经验全部命中、假设不变，则期末 EV − 期初 EV = VNB + EV 期望回报，这就是「EV 营运利润」的骨架（见下节）。

为什么这是 2026 真题简 3 的满分答案：真题问「EV 波动的原因」——骨架答案列五大原因；进阶答案直接搬本节结构：转移项给增长（VNB + 期望回报），非转移项给波动（经验偏差 + 假设变化 + 投资差异），其中投资回报差异是主导波动源（敏感性 ±20% vs 其他 ±5% 以内）。一句话点破「增长是必然项、波动是差异项」的数学结构。

04内含价值利润与营运利润体系 ★★教

把 EV 变动分析套上「考核」目的，就得到内含价值口径的利润体系：

EV 营运利润 = 当期 VNB + 上期末有效业务的期望利润释放 ± 经验偏差 ± 非经济假设变化（经济假设变化与投资差异单列）
EV 利润 = EV 营运利润 + 投资回报差异 + 经济假设变化影响 + 自由盈余投资收益 ± 其他
  • 营运口径剔除市场噪声（投资差异、经济假设变化），考核管理层可控的经营质量——对应「内含价值营运利润」披露；
  • 全口径 EV 利润再纳入市场项，反映股东价值的实际增减；
  • 与会计利润的关系：会计利润按权责发生制分期确认（CSM 摊销后置），EV 利润在签单时点前置确认 VNB——两者长期趋同、节奏迥异，调节表是投资者沟通的关键披露。
考核应用：长周期考核（2022~2025 改革：3 年 / 5 年权重 50% / 20%）正是为了抑制全口径 EV 利润的市场噪声，把管理层激励锚定在营运项——VNB 质量与经验偏差管理上。这条链写进「价值管理如何落地」论述题，直接升维。

05RDR 的确定：风险折现率的解剖手术 ★★★规题

RDR（风险折现率）是 VIF 折现的灵魂参数——它每 +50bps，EV 约 −5%。精算讲堂给的标准解剖：

RDR = 无风险利率 + 权益风险溢价 × 业务风险加载（β 思路）+ 非流动性溢价 − 税收调整
成分取值逻辑敏感性
无风险利率长期国债收益率（与负债久期匹配的期限）随行就市
风险溢价反映未来现金流的不确定性（死亡率 / 退保 / 费用 / 投资）每 50bp → EV ∓5%
流动性溢价有效业务现金流长期锁定 → 投资者要求补偿与会计折现率差异的主要来源
税收税后口径（股东视角）口径错误系统性偏差

与 CoC 的对偶关系：RDR 用于折 VIF 现金流；CoC（要求资本成本）单独计量 RC 被锁定的机会损失——两者都反映资本占用代价，但对象不同（VIF vs RC），别在计算里重复扣或漏扣。标准要求 RDR 的确定方法与变动历史必须披露；敏感性分析强制 RDR ±50bp 情景。

06MCEV vs TEV：两条技术路线的终局对决 ★★教

欧洲市场（CFO 论坛）曾全面推行 MCEV（市场一致内含价值），中国与多数亚洲市场保留 TEV（传统内含价值）。两者分歧集中在三处：

分歧点MCEV（市场一致）TEV（传统）
折现率与金融负债同期限的无风险曲线 + 流动性 / 风险溢价，盯市锁定式 RDR（11% 量级，历史惯性）
金融选择权与保证（FOG）市场一致定价（随机模型 / 期权定价），价值随市波动确定性情景评估，通常低估
成本与透明度假设复杂、结果波动大、与市场沟通难简单稳健、可比性强、波动小

中国现状的标准答法：国内金融衍生品市场与定价工具尚不成熟，负债内嵌选择权缺乏可靠的对冲价格基准，现阶段 TEV（2016 标准）可靠性更高；随着 IFRS17 的市场一致计量落地与新准则过渡完成，EV 标准向市场一致性靠拢是长期方向——这也是「标准若修订」预警的技术背景。

核心问题自测

中国 EV 体系三个文件与两次换轨？

2005 编制指引（起点）→ 2010 评估标准试行（四要素框架）→ 2016 现行标准（与偿二代衔接）。两次换轨：偿二代（RC 改最低资本口径，EV 与偿付能力共享资本模型）、IFRS17（CSM 与 VIF 双轨并存，调节表成新课题）。

EV 变动分析的转移项与非转移项划分？

转移项（预期内）：VNB、EV 期望回报——假设命中时的必然变动，是考核基线；非转移项（未预期）：经验偏差、假设变化、投资回报差异、模型调整——真正的价值创造 / 毁灭来源。投资回报差异通常是最大波动项。

未来新业务价值两算法与收购溢价五条？

乘数法（VNB × 5~10 倍，速算）vs 逐单预测法（业务计划逐年折现，正式定价）。EV ≠ 收购价五条：不含新业务、商誉与整合成本、控制权溢价、收购方 RDR 重估、税务与资本摩擦。

RDR 四成分与 CoC 的对偶？

RDR = 无风险利率 + 风险溢价 × 业务风险 + 流动性溢价 − 税收调整；每 +50bp → EV 约 −5%。CoC 计量 RC 被锁定的机会成本——对象不同（VIF vs RC），二者并存不可重复扣。标准强制披露 RDR 确定方法与 ±50bp 敏感性。

01导语：一句「错配」贯穿二十年考题

保险公司这门生意的本质，是先收钱、后付钱——资产端与负债端天然不同步：期限不同步、利率敏感性不同步、现金流节奏不同步。这个「不同步」就叫错配（mismatch）。ALM（Asset & Liability Management，资产负债管理）就是经营错配的艺术：在可承受的风险内，让资产与负债的对话尽可能和谐，从而实现财务安全与价值增长的平衡。

翻开二十年真题，「资产负债匹配 / ALM 目标与流程」以 9 次 位居所有考点之首——2009 年以前考、2013 年考、2014 年考、2017 年考、2026 年还在考（「优化 SAA」「传统险账户如何匹配降波动」）。它不出偏题怪题，答案框架相对固定，是全卷性价比最高的 10%。

图谱核心问题自测（先自己答，再展开对照）

1.1 ALM 的定义三要素与目标三层是什么？

定义三要素：① 风险偏好约束下（不是无条件追求收益）；② 资产端与负债端协同管理（不是各自为政）；③ 实现财务安全性与盈利性的动态平衡（不是一次性静态匹配）。目标三层：安全层（偿付能力与流动性底线）→ 收益层（风险预算内的利差）→ 价值层（EV 与市场价值最大化）。

1.2 ALM 六步流程与四大途径分别是什么？

六步：设定风险偏好与目标 → 分析负债特性 → 制定 SAA/TAA → 量化评估与监控 → 执行与再平衡 → 报告与反馈。四大途径：现金流匹配（完全免疫但成本高）、久期免疫（易实施但仅防平行移动）、最优化方法（系统化但模型风险）、DFA（捕捉动态交互但解释门槛高）。

1.3 董事会 / ALM 委员会 / 工作小组 / 精算部 / 财务部 / 投资部的职责各一句话？

董事会——批准风险偏好与 ALM 政策、承担最终责任；ALM 委员会——跨部门定策略、审限额、协调两端冲突；工作小组——日常监控指标、识别错配、提再平衡建议；精算部——负债评估、久期与现金流预测、定价与投资假设一致性；财务部——会计计量、资本规划、绩效考核衔接；投资部——SAA/TAA 落地、组合久期与再平衡、衍生品对冲。

1.4 五类负债的"性格"与万能险负债特征五条？

传统险——久期长、保证刚性、资产端必须拉长久期；分红险——红利浮动半缓冲、需稳定可分配盈余；万能险——结算利率上不封顶下有保底、退保选择权、账户独立；投连险——风险全在客户、ALM 压力最小；非寿险——短周期、赔付厚尾、适合流动性分层而非完全匹配。万能险五条：账户制透明、结算利率竞争刚性（棘轮）、退保选择权、缴费灵活、分账户管理。

1.5 我国资产驱动型产品的三次浪潮与触发监管的节点？

① 2000 前后——高预定利率（复利 6.5%~8.8%）传统险锁定，降息周期酿成 90 年代利差损存量；② 2000~2013——分红 / 万能 / 投连新型产品，浮动机制部分转嫁利差风险；③ 2014~2016——高现价中短存续期万能险"短钱长配"爆发，触发 2017 年起严监管；2017 至今回归保障 + 报行合一 + 规则 4 号量化硬约束。

1.6 中国 ALM 监管"三级跳"的三个文件与核心内容？

① 2019 年 32 号《保险资产负债管理监管暂行办法》——能力评估 + 量化评估双轨、结果挂钩监管措施；② 监管规则第 1~5 号——第 4 号量化评估（30/40/30 权重 + 两道一票否决）、第 5 号报告要求（年度 5 月 31 日前）；③ 2026 年《关于加强资产负债管理的通知（征求意见稿）》——久期错配缺口上限（人身险 7 年）+ 考核机制改革时间线。

1.1 ALM 的定义与目标 ★★教

定义（三要素缺一不可）：资产负债管理是在风险偏好约束下，通过对资产端与负债端的协同管理（而非各自为政），实现财务安全性与盈利性的动态平衡的技术与制度安排。

目标三层（答题模板）：

  • 安全层：维持充足的偿付能力与流动性，守住不发生「技术性破产」的底线——对应偿付能力监管与现金流测试；
  • 收益层：在既定风险预算内追求投资收益与负债成本的利差——对应成本收益匹配与再投资管理；
  • 价值层：最大化公司内涵价值与市场价值——EV、NBV 与股东回报最终都落在这里。
答「ALM 目标」类题目：先点「风险偏好约束下」（体现 ERM 语感），再展开三层目标，最后落到「资产负债两端协同决策、动态调整」——比背单句定义多拿一半分。

1.2 ALM 流程与四大途径 ★★★教题

ALM 六步流程闭环（2014/2013 两度直接命题「阐述 ALM 流程」）：

设定风险偏好与 ALM 目标 —— 董事会层面批准，量化为久期限额、错配限额、偿付能力底线等指标。
分析负债特性 —— 期限、久期、利率敏感性、现金流形态、期权性（退保/结算利率选择权）。
制定资产配置策略（SAA/TAA） —— 战略配置定长期错配格局，战术配置做短期偏离。
量化评估与监控 —— 久期缺口、现金流匹配、成本收益匹配、压力测试（详见专章 B）。
执行与再平衡 —— 通过资产调整、产品调整、再保险、衍生品对冲纠偏。
报告与反馈 —— 定期向 ALM 委员会/董事会报告，触发限额检视与目标修订。

四大经典途径（2013 年第 16 题「ALM 主要途径并举例」）：

途径核心思想优点局限
现金流匹配每期资产现金流 ≥ 负债现金流（完全匹配/专门组合）免疫一切利率风险，逻辑最彻底成本高、约束多；非寿险等不规则现金流几乎无法实现
久期免疫资产久期 = 负债久期（进一步可加凸性匹配）易实施，只盯久期一个指标仅对平行移动免疫；收益率曲线非平行变动时失效
最优化方法在约束下求解目标函数（如最大化利差 / 最小化错配方差）系统化、可嵌入监管与风险预算约束依赖假设与估计误差，模型风险
动态财务分析 DFA随机情景模拟资产负债表随时间的联合演化捕捉动态交互与尾部风险，支持前瞻决策计算复杂、结果解释门槛高（2014 年分红险 DFA 步骤题）
口诀匹配免疫最优化，随机模拟看天下；平行移动找久期，非平扭曲靠 DFA。

1.3 组织架构与职责 ★★★教规题

「ALM 委员会、工作小组、精算部、财务部、投资部各自职责」在 2013、2014 连续两年考大题，属于背了就满分的送分内容：

层级职责要点关键词
董事会批准风险偏好与 ALM 政策，承担最终责任；听取重大错配与超限报告最终责任 · 批准政策
ALM 委员会跨部门决策机构：制定 ALM 策略与限额、审议配置方案、协调资产负债两端冲突、监督执行跨部门 · 定策略 · 审限额
ALM 工作小组执行层：日常监控指标、识别错配、准备报告、提出再平衡建议日常监控 · 提建议
精算部负债端专业担当：负债评估与久期分析、现金流预测、产品定价与 ALM 一致性、准备金与 EV 假设负债语言 · 现金流预测
财务部报表与资本视角：会计计量、资本规划、财务预算、绩效考核衔接资本规划 · 报表视角
投资部资产端执行：SAA/TAA 落地、组合久期管理、再平衡交易、衍生品对冲资产执行 · 组合管理
2013·25ERM 与 ALM 的关系：ERM（企业风险管理）是在统一风险偏好下对全公司风险的识别、评估、量化、监控与报告的体系；ALM 是其在「资产负债错配风险」这一维度上的深化落地。答此题需点出：ALM 关注点贯穿 ERM 的风险识别（错配计量）、风险量化（压力测试/随机模拟）、风险应对（限额与对冲）三大步骤。

1.4 负债特性图谱 ★★★教题

读懂负债，是 ALM 的第一步。五大类负债的「性格」必须能脱口而出（万能险 5 次真题，为最高频单一产品）：

负债类型期限/久期利率敏感性关键特征与 ALM 要点
传统寿险长（可达 30 年+）对客户不敏感、对公司敏感保证利率刚性锁定 → 资产端必须拉长久期对冲再投资风险；负债久期 > 资产久期是中国寿险的典型形态
分红险长半敏感红利浮动提供缓冲垫（利差可部分转嫁），但红利实现率有隐含下限压力 → 需维持稳定可分配盈余（2013/2014 分红 ALM 大题）
万能险可长可短（高现价则短）高度敏感结算利率与退保选择权双刃剑：市场利率升 → 退保套利 + 结算利率竞争；账户制管理、独立核算（详见下）
投连险随账户风险全在客户单位化负债，资产=负债动态相等，公司主要承担费用与平滑风险；ALM 压力最小
非寿险短（1 年期为主）间接赔付形态决定短尾/长尾；现金流不规则（赔付分布有厚尾），适合「分层流动性管理 + 现金流测试」而非完全匹配（2013·22 非寿险不适合现金流匹配三理由）
背一背：万能险负债特征（2013·18 / 2017·8 / 2014·25）
  1. 账户制与透明性：保费进入个人账户，结算利率逐月公布，费用扣除透明；
  2. 结算利率的竞争刚性：虽设最低保证利率，但实际结算利率受市场与同业竞争驱动，具有「可上难下」的棘轮效应；
  3. 退保选择权：客户可随时退保，利率上升时退保率上升（内嵌看跌期权），负债久期随利率环境变化；
  4. 缴费灵活：趸交/期交/追加保费灵活，负债规模与现金流可预测性差；
  5. 资产负债需分账户管理：利率敏感 + 流动性敏感，监管要求独立账户运作，资产配置须高流动性、短久期为主。
补一补：养老金业务 vs 寿险业务（2014·4 选择题考点，考纲外补充）
维度寿险业务养老金业务（DC / DB）
监管要求偿付能力监管、产品备案、精算规定养老金法规 / 税收递延政策 / 账户制监管，约束体系不同
资本状况须持有最低资本，占用股东资本并要求回报DC 受托管理几乎无资本占用；DB 计划风险由发起企业承担
资本结构"保单持有人负债 + 股东资本"结构资产属于受益人，无股东资本层
负债特性死亡 / 生存给付，久期长且有保证年金化领取（长寿风险）、工资挂钩缴费（与个人收入相关）
ALM 要点久期匹配 + 保证成本管理长寿风险对冲（长寿债券 / 生命周期下滑航道）、负债工资指数化

差异的三大根源：监管要求、资本状况、资本结构——2014 年选择题考的就是这个"为什么不同"。个人收入情况（缴费与工资挂钩）是可辩的第四条。

补一补：非寿险业务特征细分（短尾 / 长尾明细，2014·9 / 2017·7 考点）
险种尾部特征要点准备金含义
车险短尾报案快、结案快、赔付规律性强、小额高频以未到期责任准备金为主
家财险短尾（有巨灾相关性）事故突发（火灾 / 盗抢 / 台风洪涝）、单笔小额、季节性未到期 + 巨灾累积关注
货运险中短尾损失常在货物抵达时才发现 → 存在报案延迟已发生未报（IBNR）需计提
船舶险 / 远洋险中长尾 + 巨灾海难集中出险、共同海损、理赔复杂未决占比高、巨灾附加
责任险长尾报案延迟 + 法律程序 + 金额高度不确定（二维分布）未决 + IBNR 占比最高的险种

记忆钩子："车家短、货船中、责任长"——尾部长短决定负债久期与准备金结构，进而决定资产端的期限与流动性策略，这是非寿险 ALM 的总纲。

非寿险为何不适合现金流匹配（标准三理由）：① 赔付发生时点与金额不确定（报案延迟、理赔时滞、巨灾厚尾），负债现金流无法精确刻画；② 业务短期滚动（一年期），负债持续期随续保波动，匹配方案需不断重构、成本过高；③ 现金流匹配要求资产期限贴合负债，但财险资金本就以流动性为先，强行匹配牺牲收益。替代方案：流动性分层 + 压力测试 + 再保险。

1.5 资产驱动型产品演变 ★★教题

「资产驱动型产品」是理解中国寿险近二十年沉浮的钥匙，2013/2014 连续命题。演变三浪潮：

2000 前后传统 fixed guarantee 时代：高预定利率（复利 6.5%–8.8%）锁定，随后降息周期酿成 90 年代利差损存量——「负债驱动」但负债定价失当。
2000–2013分红/万能/投连「新型产品」时代：浮动收益机制把部分利差风险转嫁客户，结算利率与分红平滑成为 ALM 新课题。
2014–2016资产驱动型高现价产品爆发：中短存续期万能险「短钱长配」，投资端激进（举牌上市公司），负债端高结算利率刚性——ALM 严重失衡，触发 2017 年起中短存续期产品严监管。
2017 至今回归保障 + 「报行合一」+ 久期匹配监管硬约束（规则 4 号量化评估），行业从「规模冲动」转向「质量优先」。
2014·23「新债还旧债」不可持续：财险公司靠不断的新保费流入兑付旧赔付与负债（类似庞氏结构）。当保费增速放缓、赔付高峰来临或再融资受阻时资金链断裂——本质是用流动性掩盖承保亏损，必须以承保盈利 + 投资收益的「双轮」替代单一滚动依赖。

1.6 监管语境的 ALM ★★规

中国 ALM 监管从「原则倡导」走向「量化硬约束」的三级跳（详见专章 B/D）：

  • 《保险资产负债管理监管暂行办法》（2019，原银保监办发〔2019〕32 号）：建立能力评估（制度健全性）与量化评估（匹配有效性）双轨体系，评估结果与分公司准入、投资端试点等监管措施挂钩；
  • 《保险资产负债管理监管规则第 4 号：资产负债管理量化评估》：期限结构匹配 30% + 成本收益匹配 40% + 现金流匹配 30%，评分等级 O/1/2/3/4 档（专章 B 全拆解）；
  • 《保险资产负债管理监管规则第 5 号：报告要求》：年度报告次年 5 月 31 日前报送，季度监测报告随偿付能力季报；
  • 2026 年《关于加强资产负债管理的通知（征求意见稿）》：新增久期错配缺口上限（人身险 7 年）与考核机制改革时间线——考试「热点分」的来源（专章 D）。

05真题印证

2026·简1「回顾 ALM，优化 SAA 战略资产配置」——先答 ALM 六步流程中「分析负债特性 → 制定 SAA」的衔接逻辑，再按「久期匹配 → 流动性分层 → 收益增强」三层展开 SAA 优化建议。落点：本章 1.2 + CH.04 SAA/TAA。
2026·简8「传统险账户如何资产负债匹配以降低财务报表波动」——传统险负债刚性保证 + 久期长：拉长资产久期（国债/长债）、利率债对冲（衍生品）、减少权益与信用下沉，使资产 DV01 贴合负债 DV01，从而压平利润表与 OCI 波动。落点：本章 1.4 + 专章 B。
2017·10「选一个近期险种阐述资产负债特征与投资策略」——万能/分红/传统任选，按 1.4 负债特性表展开，投资策略须与负债性格一一对应。
2014·24「ABC 寿险 ALM 目标 / 万能险 ALM 流程 / 四部门职责」——本题是本章 1.1 + 1.2 + 1.3 的全家桶，9 分大题。
2013·24分红险为主的 ABC 公司：ALM 目标、分红业务 ALM 过程、组织职责——与 2014·24 几乎同构，证明「组织职责 + 流程」是十年级重复考点。
完整作答示范：2013·16「ALM 的主要途径，并选择两个举实例」

四大途径总述：产品管理、资产配置管理（SAA/TAA）、再保险安排、动态财务分析（DFA）/ 情景与压力测试。

实例一 · 产品管理：某公司在利率下行期开发分红型年金替代传统固定利率年金——通过红利浮动机制把部分利差风险转嫁给客户，降低负债保证成本刚性；定价时将投资假设（4.0%）与负债成本假设（预定利率 2.0% + 目标红利）做一致性校验，从源头控制错配。

实例二 · 再保险安排：人身险公司将终身寿险的一定比例分出给再保险公司——降低死亡风险的净自留敞口（保险风险最低资本下降）、缓解新业务快速扩张对资本的占用（偿二代下分出降低最低资本、提升充足率），同时应收分保改善认可资产负债表（代价是新增交易对手信用风险，分入人充足率 ≥200% 时因子仅 0.008）。

答题提示：途径名称要全列（4 个），实例要带"机制 + 数字"——两个实例分别落在负债端与资产端 / 风险端，覆盖面比两个都写资产端更得分。

完整作答示范：2013·18「万能险负债特征的几个方面」

五条：① 账户制与透明性——保费进个人账户、结算利率逐月公布、费用扣除透明；② 结算利率竞争刚性——虽设最低保证利率，实际结算受同业竞争驱动，"可上难下"棘轮效应；③ 退保选择权——客户可随时退保，利率上升时退保率上升（内嵌看跌期权），负债久期随利率环境变化；④ 缴费灵活——趸交 / 期交 / 追加 / 部分领取灵活，负债规模与现金流可预测性差；⑤ 分账户管理——利率敏感 + 流动性敏感，监管要求独立账户运作，资产配置须高流动性、短久期为主。

延伸半句（拉分）：这些特征使万能险的负债久期必须用有效久期（情景重新定价）而非修正久期度量（2009 前·9 考点），且结算利率粘性正是成本收益匹配情景三（利率跳升）下利差被双向挤压的根源。

06实务视角与口诀

实务视角（一名精算师的旁白）：本章内容在实务中对应的是每月的 ALM 例会——精算部带着负债久期与现金流预测来，投资部带着组合 DV01 与再投资计划来，两边的数字在一张「缺口报表」上碰头。所谓 ALM 能力，本质是让两张报表说同一种语言。考试考的「职责与流程」，就是这张碰头会桌上的座位表。

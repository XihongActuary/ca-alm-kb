01导语：从「被动防御」到「主动经营」

1952 年，英国精算师 Redington 提出免疫（immunization）：让资产久期等于负债久期，利率的小幅平行移动就伤不到盈余。七十多年过去，ALM 从这颗种子长成了监管尺度下的参天大树——今天的规则第 4 号把「期限结构、成本收益、现金流」三大匹配变成 30/40/30 的百分制评分，ALM 从保险公司的自律艺术变成了监管的硬约束。

本章把 ALM 的「兵器谱」铺开：久期/凸性（免疫的数学）、现金流匹配（最彻底也最昂贵）、成本收益匹配（利差损的防火墙）、SAA/TAA（配置的指挥体系）、DFA 随机模拟（把一切放进未来时态）。每件兵器都对应一组真题——规则 4 号的逐项拆解在专章 B，低利率时代的错配困局在专章 D。

4.1 久期三兄弟公式、免疫三条件、久期缺口公式与方向判断？

D_mac = Σt·PV(CF)/ΣPV(CF)；D_mod = D_mac/(1+y)；D_eff = −(PV₊−PV₋)/(2·PV·Δy)。免疫三条件：资产现值=负债现值、资产久期=负债久期、资产凸性>负债凸性。久期缺口 = D_A − D_L×V_L/V_A；缺口为负（负债相对久期长）时利率下行净资产受损——中国寿险常态。

4.2 现金流匹配定义、非寿险三不适用、监管三级检验与压力参数？

定义：每期资产现金流入 ≥ 负债现金流出（严格版=专门组合）。非寿险三理由：赔付不确定、业务滚动重构成本高、牺牲流动性优先的收益。三级检验：现金 → 高流动性资产变现 → 中低流动性资产变现（测试期三年，首年按季度）；压力情景：新单 −80%、退保 max(25%, 2×基本)、固收 10% 违约同时发生；中低档变现后仍负 → 整体 0 分。

4.3 M/N/O 三个利差口径与四大压力情景？

M = G−K（综合收益率−资金成本率）、N = H−L（风险调整后收益率−保证成本率）、O = E−J（会计收益率−有效成本率）；H = RAROI 扣 8% 资本占用项（市场与信用 MC 按 ρ=0.25 相关汇总）。四情景：一宏观恶化（权益 VaR 下跌、房地产 −20%）、二长期低利率（再投资 −73%~−24%）、三利率跳升（+100bps×2、负债成本同步上调）、四非寿险影响（保费 130%/150%）。

4.4 SAA 与 TAA 的区别、新钱法 vs 整体法、账户划分？

SAA：3~10 年、负债驱动、董事会审定、每年滚动评估；TAA：1 年内战术偏离、受限额约束。再平衡：新钱配置法（作用于新增资金，成本低纠偏慢）vs 整体配置法（作用于组合整体，纠偏快成本高）。账户：普通账户（公司担投资风险，分传统/分红/万能子账户+资本金）与独立账户（客户自担）。

4.5 DFA 的定义、分红险 DFA 四步骤与三端四表？

DFA：随机情景模拟资产负债表联合演化，输出财务结果分布。分红险 DFA 步骤（2014·20）：确定情景分析 → 随机模拟情景分析 → 结果分布与极端评估 → 管理决策。三端四表：资产端 / 负债端 / 资本端 × 资产负债表 / 利润表 / 现金流量表 / 偿付能力报表；五大应用含资本规划、配置优化、新旧准则预测、边际资本占用、气候压测。

4.6 再保险对实际资本与最低资本的完整影响逻辑？

负债侧：分出 → 应收分保准备金 / 应收分保账款 / 摊回费用计入认可资产、准备金负债净额下降 → 实际资本上升（但不属于任何资本层级——不满足资本五特性）。最低资本：保险风险 MC↓（净自留敞口减少）、市场风险 MC 通常↓（投资敞口减少）、信用风险 MC↑（分入人违约风险：境内 0.008~0.745 按充足率、境外 0.077/0.499/0.867 按担保与达标）；净效应取决于分入人资质与担保安排。

4.1 久期、凸性与免疫 ★★★教题

久期家族（三个都要会算）
Macaulay 久期：D_mac = Σ [t · PV(CFt)] / Σ PV(CFt)　（现金流加权平均到期时间，单位：年）
修正久期：D_mod = D_mac / (1 + y)　（价格对利率的一阶敏感度）
有效久期：D_eff = −(PV+50 − PV−50) / (2 × PV × 0.01)　（含权资产用情景重估，万能/投连必用）
价格变动近似：ΔP/P ≈ −D_mod·Δy + ½·C·(Δy)²　（C 为凸性）

久期三兄弟怎么选（2009 年真题：比较美元久期与有效久期计量万能/投连利率风险的差异）：Macaulay/修正久期适用于现金流固定的债券与普通险负债；含退保权、结算利率选择权的万能险与投连产品，其现金流随利率变化而变化，必须用有效久期（整条曲线 ±50bps 重估）；「美元久期（DV01）」= 修正久期 × 市值，衡量金额敏感度，适合不同规模组合间的直接比较。

免疫三条件（Redington）久期相等是灵魂，现值相等是前提，凸性资产大一分。
平行移动全免疫，非平扭转需凸性——凸性资产恒大于负债，曲线任何变动下盈余不缩。
久期缺口（资产负债联合视角）
久期缺口 Gap = D_A − D_L × (V_L / V_A)
Δ净资产 ≈ −[D_A × V_A − D_L × V_L] × Δy = −Gap × V_A × Δy
Gap > 0：利率下行受益、上行受损；Gap < 0（中国寿险常态）：利率下行时资产增值不及负债增值 → 再投资风险与利差损。监管口径见规则 4 号「规模调整后的修正久期缺口」与「资产调整后的期限缺口」（后者把长投按 12 年、投资性房地产按 25 年计权）。
2017·5负债现值与久期计算 + 平均利率 vs 期限结构——三条业务线（短/中/长久期 1.73 / 4.95 / 9.36），用平均利率 2.67% 折现 vs 用逐期期限结构折现，差异要从三方面分析：①现金流形态（一次性 vs 分散）；②期限（越长对曲线形状越敏感）；③久期（平均利率抹平了期限结构信息，长端负债估值偏差最大）。本题套路在卷一完整复刻。

4.2 现金流匹配 ★★★教规题

定义：构造资产组合，使每期的资产现金流入 ≥ 负债现金流出（完全匹配的严格版即「专门组合策略 dedicated portfolio」）。与免疫的分工：免疫只盯现值敏感度（允许单期错配）、现金流匹配要求逐期覆盖（最彻底但最贵）；实务中两者混用——核心负债现金流匹配、其余久期免疫。

非寿险不适合现金流匹配的三理由（2013·22 标准答案）：① 赔付时点与金额不确定（报案延迟、长尾、巨灾厚尾），负债现金流刻画本身就不可靠；② 一年期业务滚动，负债持续期随续保率波动，匹配需持续重构、成本过高；③ 匹配导向会牺牲财险资金本应以流动性为先的收益。→ 替代：流动性分层管理 + 压力测试 + 再保险。
再保险手续费的两个概念（2013·22 第二问）：① 预付手续费（分保佣金）：分出业务时即按分保保费一定比例支付给分出人的佣金，补偿其获取成本，期初即发生；② 调整手续费（纯益手续费/利润佣金）：再保合同盈利时按约定比例向分出人返还，其时点是可预期的——因为它依附于合同结算与盈利核算的既定时间表（通常在业务年度结束后按账单核算），金额虽不确定、发生时点可预判，因而在现金流预测中可纳入规划。

监管现金流测试（规则 4 号第 9 条）：测试期未来三年（首年按季度、次年合并季度、第三年按年），覆盖普通账户（含传统/分红/万能子账户）与独立账户，做「累计现金及流动性管理工具」的三级检验：现金 → 变现高流动性资产 → 变现中低流动性资产。变现系数表：国债 95% → 政府债/准政府债/AAA 金融债 90% → AAA 非金融债/债基 85% → 上市股票/股基/可转债 80%（高流动性档）；持有至到期国债 95%…保险资管产品 75%、其他资产 60%（中低档）。压力情景（人身险）：新单保费 −80% + 退保率取 max(年化 25%, 2×基本退保率) + 到期固收 10% 违约，三者同时发生。中低流动性资产变现后仍有一期为负 → 整体量化评估 0 分（流动性的一票否决）。

4.3 成本收益匹配 ★★★规题

规则 4 号中权重最高（40%）的维度，也是 2026 年真题「成本收益匹配的挑战和机会」的直接出处。核心思想一句话：持有资产的收益必须覆盖负债的成本——利差为正是生存线。

利差指标族（寿险视角）
M = G − K：年化综合投资收益率 − 寿险业务负债资金成本率
N = H − L：风险调整后综合投资收益率 − 负债保证成本率
O = E − J：年化会计投资收益率 − 负债有效成本率（IRR 法）
H = RAROI = G − [8% × √(MC市场² + 2×0.25×MC市场×MC信用 + MC信用²)] / 资金运用平均净额
收益端区分「会计投资收益率 E」（不含可供出售公允价值变动）与「综合投资收益率 G」（含）。成本端四口径：保证成本率 L（预定利率/最低保证利率）、资金成本率 K（分红=宣告红利水平+预定利率、万能=过去12个月结算利率均值）、有效成本率 J（使负债现金流现值=资产账面的 IRR）、非寿险 R = (综合成本−已赚保费)/(准备金+净资产)。

四大压力情景（详见专章 B）：情景一宏观恶化（权益三年 VaR 下跌、房地产 −20%、利差扩大 σ=77%、关注类以下违约损失 60%、汇率 ±20%）；情景二长期低利率（再投资收益率按期限下调 −73% ~ −24%，期限越短降幅越大）；情景三利率跳升（无风险利率第 2 年 +100bps、第 3 年再 +100bps，负债成本同步上调——防的不是利差损而是「资产缩水 + 负债成本上行」的双杀）；情景四非寿险影响（保费 130%/150%、赔付费用 106%/110%）。

2026 真题「成本收益匹配的挑战和机会」· 答题框架

挑战：① 低利率下再投资收益率趋势性下行（情景二：短期限下调高达 73%），而存量保单预定利率刚性 → M 持续收窄乃至转负（利差损）；② 高预定利率存量（如 3.5% 时代产品）与新增资产收益倒挂；③ 万能结算利率的棘轮效应（资金成本率 K 黏性）；④ 中小公司高风险资产占比高，H 的风险扣减（8% 资本占用项）进一步侵蚀风险调整后利差；⑤ 会计口径与综合口径背离（OCI 波动）。

机会：① 负债端「报行合一」与预定利率动态调整机制压降 K；② 拉长资产久期锁定长端收益（超长债、REITs、另类）；③ 提高账户精细化管理，分账户匹配资产（传统/分红/万能差异化管理）；④ 金规〔2023〕5 号因子优化（沪深300 0.30 等）降低资本占用、提升 RAROI；⑤ 以成本收益匹配评分（40% 权重）为抓手，倒逼产品定价与投资策略联动。

4.4 SAA/TAA 与再平衡 ★★★教规题

SAA 战略资产配置 —— 3~10 年期，由负债特征驱动：先刻画负债久期/现金流/成本，再在风险预算与偿付能力约束下定大类资产比例（监管要求：资产战略配置规划至少三年，每年至少滚动评估一次）。
TAA 战术资产配置 —— 1 年内围绕 SAA 有限偏离，捕捉市场机会；偏离幅度受限额管理（规则 5 号：年度资产配置计划为一年期策略）。
再平衡两种方法 —— 新钱配置法：SAA 目标只作用于新增可配置资金（到期资产、利息红利、业务净现金流），交易成本低、但纠偏慢；整体配置法：直接作用于组合整体，纠偏快、但实现损益与交易成本高。
账户划分（32 号办法第 10 条） —— 普通账户（公司承担投资风险，含传统/分红/万能子账户 + 资本金账户）与独立账户（客户自担投资风险）；资本金参照普通账户管理。
2026·简1「回顾 ALM，优化 SAA」答题骨架：第一步答 SAA 的 ALM 逻辑（负债驱动：负债久期/现金流/成本约束 + 偿付能力与流动性约束）；第二步给优化动作——久期缺口管理（增配长债/超长债）、账户分治（传统账户利率债为主、分红账户适度权益、万能账户高流动性）、风险预算重分配（权益占比与资本占用挂钩）、纳入利率衍生品对冲；第三步答治理保障（SAA 由 ALM 委员会审议、董事会审定，每年滚动评估）。

4.5 DFA 与「三端四表」 ★★教题

动态财务分析（DFA）：用随机情景（利率随机模型、权益收益模型、相关性矩阵）把资产负债表的联合演化模拟上千条路径，输出未来各时点的财务结果分布。2014 年真题考过分红险 DFA 的步骤：确定情景分析（确定性情景）→ 随机模拟情景分析（随机情景）→ 结果分布与极端情况评估 → 管理决策。

ALM 模型的「三端四表」框架（精算讲堂第 16 讯）：三端 = 资产端、负债端、资本端；四表 = 资产负债表、利润表、现金流量表、偿付能力报表。五大应用场景：① 偿付能力与资本规划预测；② 资产配置优化（改进 Markowitz 有效前沿 + 资产负债约束）；③ 新旧准则财务预测（新准则下折现率变动进 OCI、非经济假设由 CSM 吸收 → 净资产波动加大，ALM 价值凸显）；④ 定制化边际资本占用测算（每类资产对最低资本的边际贡献，选配置效率高的资产）；⑤ 气候风险压力测试与碳排放测算。

资产端估值三法（DFA 建模基础）：市场价值 = 现金流按（无风险即期利率 + Spread）折现；摊余成本 = 现金流按 IRR 折现；账面价值 = 交易/可供出售类取市值、其他取摊余成本。负债端四套准备金：法定 / 会计 / 偿付能力 / 内含价值相应负债——同一负债、四种目的、四个数字，这是科目八全书的暗线。

4.6 衍生品与再保险对冲 ★★规题

利率风险对冲工具箱：

  • 利率互换：付固定收浮动 = 做空久期（资产久期过长时用）；收固定付浮动反之。偿二代口径：EX = 名义本金，收固定付浮动敞口为正。
  • 国债期货：空头对冲债券组合；符合套期有效性且期限 ≥1 个月可合并计算最低资本（组合 MC = |债券组合资本要求 − 期货空头价值 × 套期有效性 × 因子|）。
  • 股指期货/期权：对冲权益敞口（2014 年选择题：Delta 用于套期保值比率、指数期权降投连产品股票风险）。

再保险的资产负债双侧效应（2026 Excel 真题核心逻辑）：负债侧分出 → 应收分保准备金增加（认可资产）；实际资本侧按第 1 号第 38 条分级；最低资本侧「三降一升」——保险风险 MC 下降（损失发生/退保风险暴露减少）、市场风险 MC 下降（分出资产减少投资敞口，但注意资产减少的抵消）、信用风险 MC 上升（分入人违约风险：境内按充足率 0.008~0.745、境外有担保 0.077/无担保 0.499）；净效应通常为正但取决于分入人资质与担保安排。

4.7 投资理论补充卡：早期真题的弹药库 ★★教题

2009 年以前与 2014 / 2017 年卷面里散落着一批投资理论考点（马科维茨、期权、套利定价）——它们大多超出当前考纲主线，但"越是老题越可能换个马甲回来"（久期凸性就是先例）。以下卡片全部折叠存放：读得丝滑，考前再翻。

卡片一 · 马科维茨均值—方差模型（2009 前·2 完整详解见真题馆）
组合方差：σ_p² = w₁²σ₁² + w₂²σ₂² + 2w₁w₂σ₁₂　（σ₁₂ = ρσ₁σ₂）
最小方差组合：w₁* = (σ₂² − σ₁₂) / (σ₁² + σ₂² − 2σ₁₂)
含无风险资产的切点组合：w* ∝ Σ⁻¹(μ − r·1)；风险容忍度 T 的总投资比例 k* = T·(μ_t − r)/σ_t²

协方差矩阵奇异（不可逆）的四种情形：① 两资产完全线性相关（ρ = ±1）；② 某资产是其他资产的线性组合（基金完全复制指数）；③ 存在冗余资产使权重解不唯一；④ 因子模型下资产数多于独立因子数（秩亏）。判断方法：det(Σ) = 0。

与 ALM 的连接：保险资产配置 = 带负债约束的马科维茨扩展——监管规则第 4 号的 H = RAROCI 本质是"扣掉资本占用后的夏普比率"。有效前沿思想仍是 SAA 优化的数学底座。

卡片二 · 期权价格六大影响因素（2009 前·1）
因素（上升）看涨期权价值看跌期权价值
标的资产价格 S↑↓
执行价格 K↓↑
到期期限 T（欧式看涨无红利时不确定）↑↑
波动率 σ（唯一只影响波动、不影响期望的因子）↑↑
无风险利率 r↑↓
红利 / 收益 D（持有期流出）↓↑

保险语境：保单内嵌选择权正是用期权语言刻画的——退保权 = 看跌期权（保单现金价值对账户价值）、保证利率 = 利率下限（floor）、万能结算利率的"保底 + 上不封顶" = 领子期权（collar）。VIF 计算中"金融选择权和保证的成本降低 VIF"，就是这些内嵌期权权利金的精算化身。

卡片三 · put-call parity 与套利判断（2009 前·6）
C − P = S − PV(K) − PV(D)　（同一标的、同一执行价、同一期限）

套利判断三步（以原题为例：S = 20，K = 22，r = 5%，call = 5）：① 算理论关系——无红利时 C − P 应等于 S − K/(1+r) = 20 − 20.95 = −0.95，即理论 P = C + 0.95 = 5.95；② 与市场价格比较——若市价 P ≠ 5.95，买入低估腿、卖出高估腿锁定无风险利润；③ 注意题给"一年后股票 12.35"等干扰信息是情景值不是套利判断依据——套利只看当前价格与平价关系的偏离。若考虑派息 v，还要扣 PV(D)。

实务落点：组合保险（用指数期权 / 期货复制看跌保护投连账户）正是平价关系的规模应用——2014·3 选择题 D 选项考的就是这个。

卡片四 · 无套利定价与 APT（2014·7 / 2017·9）

无套利定价：若市场不存在套利机会，则存在风险中性测度（等价鞅测度）使所有资产折现价格为鞅——金融数学基本定理（FTAP），这是无套利的充要条件。资产价格随信息即时调整只是无套利的维持机制（套利者的交易使偏离瞬时消失）。

APT 套利定价理论（Ross）：资产期望收益 = 无风险利率 + Σβᵢ×λᵢ（因子风险溢价）——多因子线性模型，CAPM 是其单因子特例。系统性风险套利的三个条件（2017·9）：① 因子结构相同（同组系统性风险暴露）；② 头寸组合自融资（净投入为零）；③ 无因子敞口（β 对冲干净）→ 组合收益确定，若非零即为套利。原题给 4 条债券的双因素模型即是"找权重使两因子敞口归零"的线性方程组。

与 ALM 的连接：免疫组合本身就是"无套利思维"的资产端应用——构造对利率因子零敞口的组合；利差交易（carry trade）则是带条件（利率不跳升）的"准套利"，情景三压力测试就是在问"准套利的条件崩了怎么办"。

卡片五 · 期权组合收益图（2009 前·4：备兑头寸三变体）

设执行价 = 当前股价 P_A，记到期价 S_T，看涨期权空头收权利金 c：

头寸到期收益（S_T ≤ K 时 / S_T > K 时）形态
① 1 股 + 1 份看涨空头（S_T + c）/（K + c）备兑看涨（covered call）：收益封顶、下行有保护 c——到期价为 S_T + Min(0, K−S_T) + c
② 2 股 + 1 份看涨空头（2S_T + c）/（S_T + K + c）仍是上行封顶，但斜率未完全对冲（1 股裸露）
③ 1 股 + 2 份看涨空头（S_T + 2c）/（2K − S_T + 2c）比率备兑（2:1）：S_T 超过某点后收益反转下行（第二个空头开始裸露）——凸性为负

保险语境：卖出保险 ≈ 卖出看跌期权（收保费、承担尾部损失），巨灾再保险 ≈ 买入价外看跌对冲尾部——③ 的"收益反转"形态正是没有再保的承保杠杆写照。

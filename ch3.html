01导语：寿险公司到底值多少钱

上世纪六七十年代，英国多起针对寿险公司的恶意收购揭开了这个行业的估值困境：寿险利润具有延迟性与预期性——今天签下的保单，利润要在未来几十年逐步释放，会计报表只能看到冰山一角，于是优质公司被当成便宜货收割。1984 年，英国寿险公司率先用内含价值（EV）做市值管理，把「未来」搬进今天的报表。

中国 2005 年建立指引、2016 年升级为精算实践标准、2022 年启动修订。今天，EV/VNB 已是寿险公司战略、定价、考核、并购的通用货币——也是 2026 年真题的必答题：「上市保险公司内含价值如何计算，是否等于收购价」与「寿险公司如何提升新业务价值」。本章给出完整答案。

一句话抓住 EV：把公司拆成「净资产的现在」+「存量业务的未来」，未来按风险打折，再扣除占用资本的成本——这就是股东真正的家底。

图谱核心问题自测（先自己答，再展开对照）

3.1 EV 四要素各自的定义一句话？

自由盈余 FS——适用业务净资产中不受约束、可分配给股东的部分；要求资本 RC——适用业务对应所有者权益中受法律法规与公司内部限制、不得分配的部分；有效业务价值 VIF——有效适用业务及其对应资产未来产生的股东现金流现值（含金融选择权和保证成本）；要求资本成本 CoC——要求资本未来不能全部返还股东造成的价值损失。EV = FS + RC + VIF − CoC。

3.2 VNB 三原则与"经验偏差 vs 新业务"的边界？

VNB 三原则：签单时点计值、计算时考虑要求资本成本、包括预期续保与预期合同变动的价值。边界（标准第十八条）：与有效合同预期保费的偏差、与趸交累加型合同预期续期保费的偏差、有效业务预期保费的重新定价——三类按经验偏差处理，不是新业务；全新签发并核保录入的新保单才是新业务。

3.3 假设体系的构成与 RDR 的确定方法？

假设体系：投资回报、死亡率 / 发病率 / 退保率、费用（维持 + 获取）、税率、风险贴现率等；原则是最佳估计 + 内部一致性（投资、分红、退保等假设相互勾稽）。RDR = 无风险利率（如十年期国债）+ 风险溢价，反映适用业务的风险与未来现金流的不确定性；假设须与评估日可获取信息一致，至少每年评估一次。

3.4 EV 桥的四大类别与"预期利润不增 EV"的原因？

四大类：新业务的预期影响（VNB + 释放 + 预期利润）、经营经验的差异（退保差 / 发生率差 / 费用差 / 税务差等）、假设变化的影响、投资回报的差异（+ 其它如模型变化）。预期利润已按 RDR 折现计入期初 VIF——实现时从 VIF 释放到调整净资产，EV 总量不变；只有未预期到的偏差才真正改变 EV。

3.5 七大敏感性情景与敏感度排序？

RDR ±50bps（EV 约 ±5%）、投资收益率 ±50bps（约 ±20%，最敏感）、死亡率 ±10%（约 ±1%）、发病率及赔付率 +10%（约 ±5%）、退保率 ±10%（约 ±1%）、费用 +10%（约 ±2.5%）、负债贴现率 ±50bps。测试时负债相关假设可同时更新，最低资本预测因子可不变；披露 ANW / VIF / VNB 三个口径。

3.6 EV ≠ 收购价的五大原因与 AV 的定义？

五大原因：未来新业务（EV 不含）、控制权溢价、流动性差异、假设差异（收购方重估 + EV 非唯一价值方法）、市场环境与谈判。评估价值 AV = EV + 商誉，商誉 ≈ 一年 VNB × 乘数——EV 是底线，AV / 收购价在底线之上。

本章知识来源：中国精算师协会《精算实践标准：人身保险内含价值评估》（2016 版，核心条款第十 / 十一 / 十六 / 十八 / 四十 / 五十条）＋ 协会指定《资产负债管理》教材价值评估相关章节 ＋ 上市险企 EV 报告实务（敏感性、EV 桥披露口径）。徽章：规 = 精算实践标准与监管规则、教 = 指定教材、题 = 历年真题。全站来源地图见 首页 · 教材与制度地图。

3.1 EV 的精确定义与四要素 ★★★规题

定义（标准第十条）
内含价值 = 在充分考虑总体风险的情况下，适用业务及其对应资产产生的现金流中股东利益的现值
EV = 自由盈余 FS + 要求资本 RC + 有效业务价值 VIF − 要求资本成本 CoC
适用业务 = 人身险公司经营的所有 人身保险业务（人寿/年金/意外/健康）。EV 中不含未来新业务（第十一条）——这半句话是「EV 是否等于收购价」的第一块基石。
要素定义记忆点
自由盈余 FS适用业务资产市值 − 全部负债 − 要求资本「可自由分红的钱」
要求资本 RC评估日受法律法规和公司内部管理限制、不能分配给股东的金额「被监管锁住的钱」→ 需计算持有成本
有效业务价值 VIF有效业务及其资产未来现金流中股东利益的现值（含续保价值）「存量业务的未来」
要求资本成本 CoC要求资本及其未来变化额的现值之和（考虑其未来税后投资收益）本质 = RDR 与要求资本税后投资收益率之差；二者相等则 CoC=0

等价口径：EV = 调整净资产 ANW + VIF − CoC（其中 ANW = RC + FS）。另一理解（原理派）：EV = 当期自由盈余 + 未来各期自由盈余增加额按 RDR 折现之和。

要求资本的计量（标准附件 1）
RC = max{0, MC + max[0, CV − (RES + DPL)]} − DTL
MC=最低资本；CV=现金价值；RES=寿险合同负债；DPL=剩余边际；DTL=DPL×税率（递延所得税负债）。相应负债 = 寿险合同负债 + 剩余边际。VIF 可整体计量，但新业务价值必须按单个产品或更细维度分组确定要求资本后加总。最低资本预测可用载体法：MC = 风险载体 × 预测因子。

3.2 VIF 六注意与 VNB 三原则 ★★★规题

VIF 计算六注意（第十二条）：① 含续保价值；② 维持费用超支降低 VIF；③ 明显的预测损失可用不同 RDR 或方法处理；④ 合理考虑再保险影响；⑤ 融资性质负债（次级债、财务再保等）的现金流变化应体现在 VIF 中并与 FS、RDR 内在一致（本身从 EV 中扣除、按市值计量）；⑥ 金融选择权和保证降低 VIF（保证年金选择权、分红/万能保证、变额年金保证），技术允许时应独立随机模拟其时间价值，有困难可隐含在 RDR 中。

新业务价值 VNB（第十六~十八条）三原则：

  • 签单时点计值（不是期末）；
  • 计算应考虑要求资本成本；
  • 应包括预期续保与预期合同变动的价值。
边界题（第十八条）：以下三项作为经验偏差而非新业务处理——① 有效合同预期保费的偏差；② 趸交累加型合同预期续期保费的偏差；③ 有效业务预期保费的重新定价。反之，「有效业务价值未包含的非预期趸交累加交费、续期保费」应进 VNB（第十七条）。VNB 与 VIF 的界定范围必须内在一致。

分红/万能的处理（第45~49条）：须对未来红利水平/结算利率、客户与股东分配方法做合理假设，满足公平性 + 合理性，与投资收益率假设内在一致；分红业务价值 = 未来现金流中股东利益现值 + 股东对分红账户剩余资产享有权益的现值。

3.3 假设体系：最佳估计 + 内部一致性 ★★★规

未来经验假设原则 —— 最佳估计，综合考虑历史数据、当前经验与未来预期（第十九条）。
内部一致性（第二十条） —— 投资收益率 ↔ RDR、续期保费 ↔ 退保率/减额缴清率等必须互相咬合；假设定期重估（第二十一条）、按产品分类设定（第二十二条）、做敏感性测试（第二十三条）并披露（第二十四条）。
费用假设（第27~31条） —— 以持续经营为基础；有实际经验用「基于费用分摊的单位成本法」（超支时费用超支法调整），无经验以利润测试假设为基础；基于整个集团口径分摊，不限于保险公司自身支出。
投资收益率（第34~39条） —— 按资产未来可产生的投资回报确定，基于长期经济状况判断，考虑违约可能、未来正现金流再投资；与资产配置、RDR、资产评估方法内在一致。
风险贴现率 RDR（第40~44条） —— RDR = 无风险利率（十年期国债收益率）+ 风险溢价；溢价反映公司规模、业务性质、偿付能力充足率差异；可按产品分组差异化；融资杠杆效应体现在现金流风险调整中。
税收（第32~33条） —— 考虑现在及已知未来的税收法律变化；税前弥补亏损价值合理估计并说明。
重要性上限（第三条）：EV 与 VNB 各为「总额的 5% 与 1000 万元孰大」——近似方法造成的差异不得越过该线，且须明确说明方法差异。上市公司披露的 EV 报告须经外部审阅，至少包括：主要评估方法和假设、计算结果、相关分析、敏感性测试（第五十条）。

3.4 EV 桥：从期初到期末的完整叙事 ★★★规题

EV 是时点值，本身不反映「质量」——价值的成色要看变动来源。标准附件 2 给出 19 项分解（本表为答题骨架，逐项定义见专章 C）：

序号分项符号/要点
1期初的内含价值起点
2期初 EV 调整 = 盈余调整 + 兼并/收购 + 模型改进口径重述，使期初与本期可比
4新业务的预期影响 = 一年新业务价值 + VNB 释放 + 新业务预期利润EV 增长的核心来源（正 VNB → 增 EV）
5有效业务价值的预期影响 = VIF 释放 + VIF 预期利润VIF 按 RDR 自然增长；预期利润释放至净资产，对 EV 净影响为零
6分散效应整体计量 > 分别计量之和，通常为正
7经营经验的差异（退保/死亡发病率/费用佣金/税务/其它）实际 vs 假设——未预期利源，真正改变 EV
8运营假设的变化（退保/死亡率/费用等非经济假设主动调整）假设恶化 → 负
9经调整净值的预期收益ANW × 预期投资收益率 × (1−税率)
11投资收益差异实际投资收益 − 预期；「尤以投资收益偏差为甚」
12经济和税项假设的变动下调投资收益率假设 → 负；RDR 下降 → VIF 上升
13-17汇率变动 · 资本注入 · 股息 · 其它 · 市场价值调整注资 + / 股息 −
19期末的内含价值 = 经调整期初 EV + 内含价值运营收益（4~10）+ 收益（11~18）闭环
四条核心结论（答任何 EV 变动论述题的纲）正 VNB 添增量，预期利润左手换；
未期偏差才真利，投资偏差最凶猛；
高 RDR 快释放，假设审慎家底稳；
高质量 EV 看：偏差小、假设真、结构纯。

四条白话：① 正 VNB 增加 EV、负 VNB 减少，RDR 越高预期 EV 增长越快；② 预期到的利润不增加 EV（VIF → ANW 左手倒右手）；③ 只有未预期到的利润（经验差异）才真正改变 EV，其中投资收益偏差影响最大——高投资收益率假设是双刃剑；④ 高质量 EV = 审慎假设 + 长期较小的运营与投资偏差。

3.5 敏感性分析：七大情景 ★★★规题

2026 年真题「敏感性分析的情景」直接对应标准附件 3。测试时除股东现金流假设外，寿险合同负债假设可同时更新；最低资本预测因子可按可操作性原则保持不变。公司应呈现不同情景下的调整净资产、有效业务价值和新业务价值：

情景变动典型 EV/VNB 敏感度（示例量级）
1 · 风险贴现率± 50bps约 ±5%
2 · 投资收益率± 50bps约 ±20%（最敏感）
3 · 死亡率± 10%约 ±1%
4 · 发病率+ 10%约 −5%
5 · 退保率± 10%约 ±1%
6 · 费用+ 10%约 −2.5%
7 · 负债贴现率± 50bps—（与情景 1 方向相反作用于 VIF）
实务注脚：正因为 EV 对投资收益率假设最敏感，2023 年底上市险企集体下调投资回报率假设与 RDR 假设（应对利率下行与利差损）——这是「敏感性 → 假设 → 真实世界」的教科书级联动，答题时点出来即是亮点。

3.6 EV ≠ 收购价，及价值管理的应用 ★★★规教题

评估价值 AV（Appraisal Value）
AV = 内含价值 EV + 商誉 Goodwill
商誉 ≈ 未来新业务价值 = 实务中常用一年 VNB × 乘数估计
乘数取决于：业务组合、利润边际、行业增长、市场份额、竞争地位、偿付能力资本与资本支出等。

EV ≠ 收购价的五大原因（2026 真题标准答案骨架）：

  1. 未来新业务：EV 明确不含未来新业务价值（第十一条）；并购以 AV（EV+商誉）为起点，收购方为持续经营的新业务能力付费；
  2. 控制权溢价：取得控制权的交易价格通常包含控制权溢价；
  3. 流动性差异：EV 是持续经营假设下的精算账面价值，非可变现市场价；股价/交易价含流动性与情绪因素；
  4. 假设差异：EV 基于当前假设集合（最佳估计 + 特定 RDR）；收购方会按自身资本成本、自身对未来投资收益/退保/费用的假设重估（第九条：EV 不是衡量公司价值的唯一方法）；
  5. 市场环境与交易结构：利率环境、谈判、多次成交价格调整条款等，使成交价可能大幅偏离 EV。
一句话收尾：EV 是「存量业务 + 净资产」的精算价值底线；收购价 ≈ EV + 未来新业务价值（商誉）+ 控制权溢价 ± 流动性/假设/谈判调整——收购价一般高于 EV。

价值管理的五大应用：① 战略与资本决策（增资/引战/并购，用 AV）；② 产品定价与业务引导（利润测试、新业务价值率 = VNB/新单保费考核）；③ 资本管理（偿付能力、注资与分红参考）；④ 绩效考核（EV 营运利润 = 当期 VNB + 上期末有效业务期望收益 ± 经验与假设差异）；⑤ 信息披露（财报补充）。NVB 内部管理四驱动：规模与结构（渠道/产品）、业务成本（费用佣金）、业务品质（继续率/退保率/赔付率）、投资能力（收益率与资产负债匹配）。

拓展：TEV vs MCEV（答「概念演进」加分项）
维度TEV（传统·中国现行）MCEV（市场一致·欧洲 CFO 论坛 2008）
方法确定性方法保障型确定性；含期权保证产品用风险中性随机模拟
投资收益假设基于资产配置与预期收益无风险利率 + 市场一致定价
选择权与保证隐含在 RDR 中随机模拟计算 TVOG
贴现率单一百分数 = 无风险利率 + 风险边际无风险利率曲线 + 市场一致定价
资本成本RDR > 投资收益率时计要求资本息差损无息差损，但考虑摩擦成本与不可对冲风险成本

国内因衍生品市场与定价工具尚不成熟，当前采用 TEV 可靠性更高。制度建设：2005 指引 → 2016 精算师协会标准（衔接偿一代→二期、引入剩余边际、允许载体法）→ 2022.10 启动修订（与 IFRS17 利润边际信息衔接是未来方向）。

04公式与数字卡片

本章一页纸
EV = FS + RC + VIF − CoC　（= ANW + VIF − CoC；不含未来新业务）
RC = max{0, MC + max[0, CV−(RES+DPL)]} − DTL
RDR = 十年期国债收益率 + 风险溢价（规模/业务性质/偿付能力充足率）
AV = EV + 商誉；商誉 ≈ 一年 VNB × 乘数
重要性上限 = max(5%, 1000 万)；敏感性：投资收益率 ±50bps → EV ±20%（最大）
总口诀自由盈余加要求，有效业务折现收；
减去资本持有价，四项加总即含价；
新业务看签单点，含本含续不含偏；
桥上预期不增价，偏差才是真利源；
收益五十动两成，贴现五十动五分；
收购另加新业务，控制溢价再加身。

06实务视角与口诀

实务视角（一名精算师的旁白）：年报季写 EV 报告，最花时间的不是算 VIF，而是「讲故事」——EV 桥每个负项都要给董事会一个解释：假设变动为什么调？投资偏差是运气还是能力？精算师的价值在于把「数字的变化」翻译成「管理动作的回声」。反过来，考核体系里放进 VNB 和 EV 营运利润，产品部门和渠道的行为立刻改变——价值管理不是报表，是指挥棒。

预期不增值，偏差见真章；
假设谁最灵，投资五十分。

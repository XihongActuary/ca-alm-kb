00总体框架与权重表 ★★★

规则第 4 号（人身险公司资产负债管理量化评估规则）把「匹配状况」变成百分制评分：期限结构匹配 30% + 成本收益匹配 40% + 现金流匹配 30%，基本信息不计分。每季度计算并随季报报送。

维度指标权重
期限结构匹配（30%）规模调整后的修正久期缺口10%
资产调整后的期限缺口10%
利率风险对冲率5%
基点价值变动率5%
成本收益匹配（40%）成本收益匹配状况（基本情景）19%
成本收益匹配压力测试21%
现金流匹配（30%）现金流测试（基本情景）10%
现金流压力测试15%
流动性指标5%
偿付能力一票否决（不计分，是开关）—
两道一票否决：① 报告期末核心充足率 <50% 或综合充足率 <100% → 整体量化评估 0 分；② 现金流测试中中低流动性资产变现后累计现金仍至少一期 <0 → 整体 0 分。监管的逻辑：偿付能力与流动性是底线，底线破了，匹配做得再漂亮也无意义。
评估范围：母公司口径（非合并）。账户划分：普通账户（传统/分红/万能子账户 + 资本金账户）+ 独立账户；独立账户规模 ≤ 总资产 1% 的，现金流匹配按普通账户占比 100% 评价。非寿险业务占比 >90% 的公司，期限结构三项指标（对冲率等）不适用；压力情景适用性：非寿占比 >90% 只测情景一、四；<10% 测一、二、三；其余全测。情景一至三每季度、情景四每年。

核心问题自测（先自己答，再展开对照）

三大维度权重与两道一票否决？

期限结构 30%（久期缺口 10 + 期限缺口 10 + 对冲率 5 + 基点价值变动率 5）+ 成本收益 40%（基本情景 19 + 压力 21）+ 现金流 30%（测试 10 + 压力 15 + 流动性 5）。一票否决：核心 <50% 或综合 <100% → 0 分；中低流动性资产变现后累计现金仍至少一期为负 → 0 分。

久期缺口评分的 ±2 年分档与资产调整的年限设定？

规模调整后修正久期缺口：|缺口| ≤2 年得满分，分档劣化至 >8 年零分（评分线性内插）。资产调整后期限缺口中：长期股权投资按 12 年、投资性房地产按 25 年计权。

六种利率压力情景的形态与 40 年规则？

上升（全曲线 +133~+137bps）、下降（−139~−143）、倾斜上（短端 −200 / 长端 +147）、倾斜下（短端 +250 / 长端 −141）、扭转上（短端 +254 → 中端 −186 → 长端 +117）、扭转下（镜像）；所有情景 40 年以上变动为 0（终极利率锁定）。

现金流压力测试三参数（人身险）？

新单保费 −80%、退保率取 max（年化 25%，2× 基本退保率）、到期固定收益类资产 10% 违约——三者同时发生；测试期未来三年，首年按季度。

01期限结构匹配（30%）逐指标

1.1 规模调整后的修正久期缺口（10%）★★★

规模调整后的久期缺口 = D_A×PV_A + D_In×PV_In − D_Out×PV_Out
金额久期缺口 = 上式 / 1000（= 平行变动 10bps 对资产负债金额的影响）；金额久期缺口率 = 金额久期缺口 / 核心资本
D_A 资产修正久期按中债估价修正久期方法；In/Out 为资产现金流入与负债现金流出（各自的修正久期加权 PV）。

评分标准：普通账户缺口在 [-2, 2] 年内 → 直接得满分区间；缺口 <−2 年（资产久期过短，中国常态）时看「规模调整后的现金流流入修正久期」：≥5 年 → 10 分、[4,5) → 8 分、[3,4) → 5 分、[2,3) → 2 分、<2 年 → 0 分；缺口 >+2 年时看「负债现金流流出修正久期」：≥5 年 → 8 分、[4,5) → 5 分、[3,4) → 2 分、<3 年 → 0 分。记住 ±2 年的分界线与「5 年全分成」逻辑即可。

1.2 资产调整后的期限缺口（10%）★★

资产调整后的期限缺口 = D_A×PV_A + D_In×PV_In − D_Out×PV_Out + BV长投×12 + BV投资性房地产×25
把不能按现金流刻画的长期股权投资（取 12 年）与投资性房地产（取 25 年）折算进缺口。评分：缺口 ∈ [-10, +2] → 10 分；<−10 年且流入修正久期 ≥5 年 → 5 分（<5 年 0 分）；>+2 年且流出修正久期 ≥5 年 → 5 分（否则 0 分）。

1.3 利率风险对冲率（5%）★★

对冲率 = (AA不利 − AA基础) / (PV不利 − PV基础)　（不利利率情景下资产变动抵消负债变动的比例）
负债敏感度 = |PV不利 − PV基础| / PV基础；资产敏感度 = |AA不利 − AA基础| / AA基础
评分按「对冲率 × 负债敏感度」组合矩阵：对冲率 ≥40% 且敏感度 ≥8% → 5 分；20%~40% 且敏感度 ≥16% → 5 分；<8% 且敏感度 [12%,16%) → 2 分……分档线：40% / 20% / 8%（对冲率）与 5% / 8% / 12% / 16%（敏感度）。直觉：负债对利率越敏感，越需要高对冲率；负债本身不敏感的公司，做对冲徒增成本。

1.4 基点价值变动率（5%）与 DV10 体系 ★★

DV10N = −(PV+10 − PV−10) / 2　（关键期限 N 上折现率 ±10bps 对现值的冲击）
20 个关键期限年：0 / 0.5 / 1 / 2 / 3 / 4 / 5 / 6 / 7 / 8 / 10 / 12 / 15 / 20 / 25 / 30 / 35 / 40 / 45 / 50
关键久期 Dur_Key = 1000 × Σ DV10N / PV
六情景基点价值变动：DV_XN = DV10N × XN / 10；Sum_DV_X = Σ DV_XAllN + LA
基点价值变动率 = Max(Sum_DV_X) / 核心资本
评分分档：≤30% → 10 分（折半为权重 5 分）；(30,50]% → 8 分；(50,70]% → 5 分；(70,100]% → 2 分；>100% → 0 分。LA（损失吸收调整）= β_Par×Min(ΣDV_X_Par,0) + β_U×Min(ΣDV_X_U,0)，β = Min(0.4, 1−Dur_eff/Dur_mod)，LA ≤ 0——分红/万能的浮动机制能吸收部分冲击，监管予以承认。

六种利率压力情景（关键期限变动参数，bps）

上升全曲线上行，短端约 +137、长端约 +133、40 年以上为 0
下降全曲线下行，短端约 −143、长端约 −139、40 年以上为 0
倾斜上短端大幅下行 −200、长端大幅上行 +147（陡峭化）
倾斜下短端大幅上行 +250、长端大幅下行 −141（平坦化）
扭转上短端 +254 → 中端转负（10 年约 −186）→ 30 年 +117（先下后上）
扭转下与扭转上镜像对称（−200 → +179 → −112）

记忆法：平移两式（升/降）+ 形状四式（陡/平/扭上/扭下）。注意所有情景 40 年以上变动均为 0（终极利率锁定），且关键期限之间按线性插值、50 年以后等幅变动。

02成本收益匹配（40%）逐指标

2.1 收益端：E / G / H 三兄弟 ★★★

会计投资收益率 E（不含可供出售公允价值变动）
E = (投资收益 + 公允价值变动损益 + 其他投资损益 + 固收类当年可确定利息收入 + 其他可确定投资收入 − 可确定投资支出) / 资金运用平均净额
综合投资收益率 G（含可供出售公允价值变动）
G = (会计投资收益 + 可供出售类金融资产公允价值变动 + 固收类可确定利息收入…) / 资金运用平均净额
风险调整后综合投资收益率 H（RAROI）
H = G − [8% × √(MC市场² + 2×0.25×MC市场×MC信用 + MC信用²)] / 资金运用平均净额
H 的含义：把市场与信用风险的资本占用成本（按 8% 资本回报要求）从收益中扣除——同等收益率下，低资本占用的组合 H 更高，这就是「配置效率」的监管表达。计算时不考虑分红万能损失吸收效应。

2.2 成本端：L / K / J / R 四口径 ★★★

口径普通型分红型万能型中短存续期
保证成本率 L预定利率预定利率最低保证利率= 资金成本率
资金成本率 K预定利率最近一年宣告分红水平 + 预定利率过去 12 个月结算利率算术平均= 保证成本率

有效成本率 J（IRR 法）：使负债现金流折现值 = 资产账面价值的年化折现率，BV = Σ CFt/(1+J)t。非寿险资金成本率 R = (综合成本 − 已赚保费) / (非寿险准备金 + 净资产)——综合成本率 100% 意味着承保零利润，R 直接刻划「承保亏损对资本的消耗速度」。

2.3 三大利差指标与评分 ★★★

M = G − K（综合口径，5 分）　N = H − L（风险调整口径，5 分）　O = E − J（会计口径，5 分）
S = G − R（非寿险：综合收益率 − 非寿险资金成本率，15 分）
三口径设计意图：M 看「钱袋子真实利差」（综合收益含浮盈）、N 看「扣掉资本占用后还剩多少」、O 看「会计报表口径利差」——三者同查，无处藏拙。

基本情景评分（19%）：对普通账户 + 传统/分红/万能分账户评估——普通账户差额 ≥0 且所有子账户 ≥0 → 5 分；普通 ≥0 但有子账户 <0 → 3 分；普通 <0 → 0 分。中短存续期产品单独 4 分（每有一个差额 <0 扣 1 分）。

2.4 四大压力情景（21%）★★★

情景核心参数考法
一 · 宏观经济恶化境内外股票基金按 99% 置信三年 VaR 下跌、其他权益减值 15%；投资性房地产 −20%；利差扩大 σ=77%（BV_down = BV×(1−σ×Dur_spread×S)）；关注类及以下违约损失 60%；人民币汇率不利波动 20%当期利差冲击
二 · 长期低利率存量固收期望收益不变，再投资收益率按期限下调：1 年期 −73% … 10 年 −37% … 20 年以上 −24%（期限越短降幅越大）；负债保证成本率不变未来三年利差（短端再配置最痛）
三 · 利率跳升无风险利率：第 1 年不变、第 2 年 +100bps、第 3 年再 +100bps；负债资金成本率同步：万能/中短 +100bps，分红 +100bps×保户分配比例；权益取基本假设与过去三年实际均值的较小值「资产缩水 + 负债成本上行」双杀
四 · 非寿险影响保费增长率 = 基本情景 ×130%（开业满三年）/×150%（未满）；赔付率与费用率 = ×106% / ×110%非寿险占比大的公司

压力测试评分（21%）：情景一按当期整体差额分档（≥0 → 7 分；[−2%,0) → 5 分；[−5%,−2%) → 3 分；[−10%,−5%) → 1 分；其余 0 分）；情景二/三各 7 分，按未来三年每年年末普通账户及各账户利差：三年全 ≥0 → 7 分；普通每年 ≥0 但有子账户 <0 → 5 分；仅两年普通 ≥0 → 3 分；仅一年 → 1 分；三年均 <0 → 0 分。

03现金流匹配（30%）逐指标

3.1 流动性比例（5%）★★

流动性比例 = (流动性资产 + 剩余期限 1 年以上政府债券/准政府债券) / 上季末总资产
分母扣除债券回购融入资金与独立账户资产。评分只有一条线：≥5% → 5 分；<5% → 0 分。2026 Excel「流动性指标计算 + 异常判断 + 三条建议」即源于此。

3.2 现金流测试：三级检验体系（10% + 15%）★★★

第一级：累计现金及流动性管理工具 —— 不动资产，纯现金视角：账户累计余额未来各期是否 ≥0。
第二级：+ 高流动性资产变现 —— 国债 95%、政府债/准政府债/AAA 金融债 90%、AAA 非金融债/债基 85%、上市股票/股基/可转债 80%。
第三级：+ 中低流动性资产变现 —— 持有至到期国债 95%…保险资管产品 75%、其他资产 60%；已质押/抵押/信用增级的资产不可变现。

测试期间：自报告期末未来三年（首年按季度、次年合并剩余季度、第三年按年）。基本情景评分（10 分）：全账户全程 ≥0 → 10 分；普通 ≥0 但子账户有负 → 8 分；普通有负但二级后 ≥0 → 5 分；三级后才 ≥0 → 0 分；三级后仍有负 → 整体 0 分（一票否决）。压力情景（15 分）：12/10/5/0 分同构递减。

现金流压力情景（人身险，三者同时发生）
新单保费同比 −80%
退保率 = max(年化 25%, 基本情景 × 2)（绝对值 ≤100%）
预测期内到期固收资产 10% 无法收回本息
财险版：保费 −50% + 综合成本率 ×130%；再保版：巨灾致分保赔付 +50% + 非关联方应收分保账款 30% 无法收回。

3.3 偿付能力压力测试必测情景（配套，规则附件 4）★★

公司必测压力情景年度敏感性必测因素
人身险① 保险风险：新单 130% 或 70%、死亡 +10%、退保 +20%、疾病 +15%、费用 +10%；② 宏观：无风险曲线 +50BP、权益 −20%、固收违约损失 10%；③ 利率风险：不利情景参数 ×130%750 日曲线平行下移 50BP；权益 −30%
财产险① 保险风险：保费 ×120%、综合成本率 ×110%；② 宏观：同上保费 ×130%；权益 −30%

04配套规则：5 号报告 + 32 号办法

4.1 监管规则第 5 号：报告要求 ★★

  • 季度报告：量化评估表 + 匹配结果变化与原因 + 主要风险 + 化解措施；季末后 30 日内报送；董事长、总经理签字。
  • 年度报告六部分：公司信息 / 董事会和管理层声明 / 基本情况 / 业务规划和资产配置 / 资产负债管理与评估 / 外部机构意见；每年 5 月 31 日前报送；七高管签字（董事长、总经理、财务负责人、精算负责人、投资负责人、首席风险官、合规负责人），共同和连带法律责任。
  • 业务规划至少三年（含各类产品未来三年预期保费）；资产战略配置规划至少三年、每年至少滚动评估一次（六项内容：决策依据、长期收益目标、大类资产配置比例、允许/限制/禁止标准、流动性要求与再投资计划、会计分类原则）；回溯分析含保费偏差、收益率偏差、配置比例偏差。
  • 第三方独立审核（会计师事务所/精算咨询公司）：历史财务信息、预测方法合规性、基本情景假设合理性、压力情景一致性、计算结果完整性——意见分无保留/保留/否定/无法表示意见。

4.2 银保监发〔2019〕32 号：暂行办法 ★★

模块要点
组织架构董事会下设资产负债管理委员会，高管层下设资产负债管理执行委员会，牵头部门任秘书处；总资产 <1000 亿的财险公司可不设委员会
董事会职责承担最终责任：审定 ALM 总体目标与战略、审定制度、审定资产配置政策
执行委员会日常管理、沟通协商机制、审议资产配置政策及调整、组织实施、控制风险
能力评估（5 维度）基础与环境 · 控制与流程 · 模型与工具 · 绩效考核 · 管理报告（百分制，现场+非现场，材料调阅/查验/问卷/质询/穿行测试）
量化评估（3 维度）期限结构匹配 · 成本收益匹配 · 现金流匹配（即规则 4 号）

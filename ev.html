00一条公式读懂 EV ★★★

价值评估篇章（考纲权重 25%）的主线只有一条公式，但每一个正负号都值得抠：

EV = 自由盈余 FS + 要求资本 RC + 有效业务价值 VIF − 要求资本成本 CoC
等价口径：EV = 调整净资产 ANW + 扣除要求资本成本后的有效业务价值（ANW = RC + FS）
标准第十条的精确定义：在充分考虑总体风险的情况下，适用业务及其对应资产产生的现金流中股东利益的现值。适用业务 = 人身保险公司经营的所有人身保险业务（人寿、年金、意外伤害、健康）；EV 不含未来新业务（第十一条），且是时点值——本身无法反映"质量"，要靠 EV 桥判断。
组成一句话定义关键记忆点
自由盈余 FS资产市值 − 所有负债 − 要求资本，可以自由分配给股东的部分钱包里随时能分红的钱
要求资本 RC受法律法规和公司内部管理限制、不能分配给股东的金额锁在保险柜里的钱 → 持有它有成本（CoC）
有效业务价值 VIF有效业务及其对应资产未来现金流中股东利益的现值（资产基础 = 支持有效业务负债的资产）存量保单未来利润的折现，含续保价值
要求资本成本 CoC评估时点 RC 与其未来每期变化额的现值之和（考虑 RC 的未来税后投资收益）本质 = RDR 与 RC 实际税后投资收益率之差；二者相等时 CoC = 0

另一种等价理解（原理分析视角）：EVt = FSt + PV(ΔFSt)——内含价值 = 当期自由盈余 + 未来各期自由盈余增加值按 RDR 折现的现值。这一视角把 EV 与"自由现金流折现"的经典估值直觉接通了。

内含价值演算器 四要素 → EV 与敏感度
内含价值 EV = FS + RC + VIF − CoC—
投资收益率 ±50bps 情景（敏感度约 ±20%）—　/　—
风险贴现率 ±50bps 情景（敏感度约 ±5%）—　/　—
单位：亿元。下方两条敏感度线直接量化了第五节的核心结论——投资收益率假设动 50 个 bp，EV 的波动是 RDR 同幅波动的 4 倍。答题时先写公式，再给敏感度排序，最后落到"假设设定的审慎性"，层次就齐了。
用演算器体会三件事：① CoC 前面是减号——RC 越大，锁得越多，EV 被扣得越多，但别忘记 RC 本身以正号加回（净影响 = RC − CoC > 0）；② VIF 通常占 EV 的大头（默认值下约 76%），这就是为什么 EV 对折现与投资假设如此敏感；③ 把 FS 改成 0、CoC 改成 0，看 EV 与 VIF 的关系——理解"简式 EV ≈ 净资产 + VIF"在什么条件下成立。

本专章知识来源：中国精算师协会《精算实践标准：人身保险内含价值评估》（2016 版）——第十条定义、第十一条不含未来新业务、第十六条 VNB、第十八条经验偏差边界、第二十六条灵活缴费、第四十条假设、第五十条披露；敏感性七情景出自该标准附件 3；EV 桥 19 项出自附件 2 分析要点。2026 真题简 3、简 4、简 7 与科目十交叉的"新业务价值敏感性"均出自本章体系。徽章：规 = 精算实践标准、题 = 历年真题、教 = 指定教材。

核心问题自测（先自己答，再展开对照）

EV 一条公式与"两个不含"？

EV = FS + RC + VIF − CoC（等价 = ANW + 扣 CoC 后的 VIF）。两个不含：不含未来新业务（第十一条）、不含非适用业务；且是时点值——质量要靠 EV 桥判断。

RC 的计量公式与 CoC 何时为零？

RC = max{0, MC + max[0, CV − (RES + DPL)]} − DTL（MC 最低资本、CV 现金价值、RES 准备金、DPL 递延保费负债、DTL 递延所得税负债）。CoC = RDR 与 RC 实际税后投资收益率之差对 RC 现值的影响——两者相等时 CoC = 0。

EV 桥四大类别与四条核心结论？

四大类：新业务的预期影响、经营经验的差异、假设变化的影响、投资回报的差异（+ 其它）。四条结论：预期利润不增 EV（已在 VIF 里）；EV 增长靠 VNB；经验偏差与假设变化是未预期利源；投资偏差是最大波动项。

敏感性七情景与最敏感假设？

投资收益率 ±50bps → EV 约 ±20%（最敏感，RDR 同幅的 4 倍）；RDR ±50bps → ±5%；发病率及赔付率 +10% → ±5%；费用 +10% → ±2.5%；死亡率 / 退保率 ±10% → 约 ±1%。披露 ANW / VIF / VNB 三个口径。

01精确定义与计量口径 ★★

1.1 相应负债与要求资本的精细公式（标准附件 1）

相应负债 = 寿险合同负债 + 剩余边际
要求资本 RC = max{ 0, MC + max[0, CV − (RES + DPL)] } − DTL　（CV=现金价值，RES=寿险合同负债，DPL=剩余边际，DTL = DPL × 税率）
自由盈余 = 资产的市场价值 − 适用业务对应的所有负债 − 评估时点的要求资本
"所有负债"= 相应负债 + 其他负债（应付保单红利、应付赔款、以市值计量的融资性负债、递延所得税负债等）。剩余边际为不确认首日利得而设立：签单时若寿险合同负债 <0，则 DPL = |寿险合同负债|，在保险期间内摊销（载体可用有效保单件数、有效保额等）。
  • 计量单元：VIF 可以整体作为计量单元；但新业务价值必须按单个产品或更细维度分组确定要求资本后加总——这是边界判断题的高发点。
  • 最低资本预测——载体法：MCti = RDti × Si（RD 为风险载体，S 为评估时点确定的预测因子），偿二代二期下允许，显著提高模型效率；退保风险最低资本 = max(大规模退保风险 MC, 退保率风险 MC)——两大块取大，不叠加。
  • 资产评估基础是市场价值（第十三条）；无市场价值的用一致方法评估重要资产并定期评估。融资性质负债与再保险（次级债等）按市场价值从 EV 中扣除（第十四条）。
  • 集团口径：集团 EV 可加上非适用业务子公司的净资产（按会计准则核算，第五十一条）。

02VIF 六注意与 VNB 三原则 ★★★

2.1 VIF 计算六注意（第十二条，逐条可考）

含续保价值续保 = 期满后投保人缴费保持合同有效；VIF 天然包含预期续保的未来价值。
维持费用超支降低 VIF所有未来维持费用超支都要吃掉存量业务价值——费用管控直接体现在价值里。
明显的预测损失可用不同风险贴现率或不同方法处理（不能假装看不见）。
合理考虑再保险影响分出业务改善偿付能力但分走利润，两侧都要进模型。
融资性质负债 / 财务再保险引起的现金流变化应体现在 VIF 中，并与自由盈余、RDR 的确定方式保持内在一致。
金融选择权和保证降低 VIF保证年金选择权、分红保证、万能保证、变额年金保证（不含提高保额等普通保险选择权）。技术允许时应独立考虑时间价值（以评估日资产组合为出发点做随机模拟）；有困难时可在 RDR 中隐含考虑。时间价值 = 期满前行权利益相对评估日行权利益的潜在增加价值。

2.2 新业务价值 VNB（第十五~十八条）

VNB 三原则：① 报告期间销售的新保单在签单时点的价值；② 计算时应考虑要求资本成本；③ 应包括预期续保和预期合同变动的价值。VNB 与 VIF 的界定范围须内在一致——有效业务价值未包含的趸交累加交费、续期保费等预期变化放在 VNB 中。

边界判断题（第十八条）：应作为"经验偏差"而非"新业务"处理的三种情形——① 与有效合同预期保费的偏差；② 与趸交累加型合同预期续期保费的偏差；③ 有效业务预期保费的重新定价。
判断口诀："预期之内的变化早已在模型里，实际与预期的差才是偏差；全新签单才是新业务。"

2.3 分红险与万能险的价值（第四十五~四十九条）

分红险业务价值 = 未来分红保险现金流中股东利益的现值 + 股东对分红账户剩余资产享有权益的现值
剩余资产 = 所有未来红利分配完后仍剩余的分红账户自由资产。假设须满足公平性原则和合理性原则，与投资收益率假设内在一致，合理考虑消费者预期与市场因素。万能险对应的是"未来结算利率确定方法"的假设。

03预测假设体系：最佳估计 + RDR ★★

3.1 总原则（第十九~二十六条件）

  • 未来经验假设原则：采用最佳估计，合理考虑历史数据、当前经验和未来预期；经验数据可来自公司内部或外部。
  • 内部一致性：投资收益率假设 ↔ 风险贴现率假设、续期保费预测 ↔ 退保率/减额缴清率假设，彼此不能打架。
  • 定期重新评估、必要时及时调整；不同类别产品按特性分别设定；对主要假设做敏感性测试并披露主要预测假设。
  • 非经济假设（死亡率、疾病率、残疾率、事故发生率、退保率、减额缴清率、部分退保率、年金选择权、红利选择权）：最佳估计，根据历史经验和未来趋势确定。
  • 灵活缴费产品：可合理预测未来保费的，应将未来保费期望水平包含在 EV 计算中。
  • 费用假设：以持续经营为基础，与中长期业务规划一致，考虑通胀与对管理系统的投资；有实际经验 → 单位成本法（现单位成本高于长期期望时用费用超支法调整）；无经验 → 以利润测试假设为基础；且应基于整个集团为适用业务支出的所有费用（含控股公司成本分摊），不限于保险公司自身。
  • 税收与法律：考虑现在及已知的未来变化；税前弥补亏损的价值合理估计并说明处理方法。

3.2 两大经济假设

投资收益率：按适用业务对应资产未来可产生的投资回报确定——长期经济状况判断 + 未来违约可能性 + 未来正现金流再投资，与资产配置、RDR、资产评估方法三重匹配
风险贴现率 RDR = 无风险利率 + 风险溢价　（无风险利率参考十年期国债收益率或其他合理利率）
风险溢价反映未来现金流风险（市场与投资风险等综合情况及其他环节未考虑到的所有风险），应体现公司规模、业务性质、偿付能力充足率差异；不同产品分组可有不同风险溢价；融资性质负债/再保险的财务杠杆效应应体现在现金流预测的风险调整中；合理考虑金融选择权和保证的时间价值、负债审慎性水平、要求资本水平和成本与 RDR 的相互关系。
重要性上限（第三条，选择题常客）：使用近似方法或其他方法处理时，差异不能超过——内含价值：EV 总额的 5% 与 1000 万元孰大；新业务价值：VNB 总额的 5% 与 1000 万元孰大。如使用与标准有差异的方法，须明确说明。
上市披露（第五十条）：上市公司应公开披露经外部审阅的 EV 报告，至少包括主要评估方法和假设、计算结果、相关分析、敏感性测试四块。标准解释修订权归中国精算师协会（第五十二条）。

04EV 桥 19 项全景拆解 ★★★

EV 桥是回答"内含价值为什么从期初变到期末"的完整叙事。简式（精算讲堂版）七个词串起主干：

期初EV + 资本增资 + 当年新业务价值 + 上年末有效业务期望收益 + 经验偏差(非投资) + 经验偏差(投资收益) + 假设偏差 = 期末EV

标准附件 2 把它展开成 19 项。全表如下（符号列为对 EV 的典型影响方向）：

序分项含义符号
1期初内含价值调整盈余调整 + 兼并/收购 + 模型改进，使期初 EV 与本期口径可比视调整方向
3经调整的期初内含价值= 1 + 2（重述后的起点）—
4.1一年新业务的价值当年签发新单在签单时点的价值（含 CoC）——EV 增长的核心来源正 VNB → 增；负 VNB → 减
4.2/4.3新业务价值的释放 + 预期利润新业务 VIF 按 RDR 自然增值并释放利润到净资产；合并后 ≈ 按经过时间加权的 VNB 利息正
5.1有效业务价值的释放期初 VIF(CRC) 按 RDR 自然增长正
5.2有效业务价值的预期利润预期利润从 VIF 释放至调整净资产对 VIF 负 / 对 ANW 正，对 EV 净影响为零

4.1 归因公式（原理分析文，简答题加分项）

ΔVIF(CRC)t = RDR × VIF(CRC)t−1 − 税后预期利润 + (RDR − ie(1−Taxrc)) × RCt−1
读法：VIF 预期释放 = 上期 VIF 按 RDR 自然增长 − 预期利润释放 + 要求资本成本当期释放。当 RDR = i(1−Tax) 时 CoC 恒为 0。利源拆分口径：退保差 = 预期退保现金流 − 实际退保现金流 + 准备金释放差；死差、费差同构；只有引起保单脱退的因素（退保、死亡、重疾）才造成 VIF 的实际与预期差异，脱退归因可按实际脱退件数比例分摊。
四条核心结论（背到就是分）① 正VNB增EV，负VNB减EV，高RDR抬高预期增速；
② 预期到的利润不增加EV——左手VIF倒右手ANW；
③ 未预期到的偏差才改变EV，投资偏差为甚——高投资假设是双刃剑；
④ 高质量EV = 审慎假设 + 长期小的运营与投资偏差。

05敏感性分析：七大情景与量级 ★★★

2026 真题直接考了敏感性分析情景。标准附件 3 给出七个建议情景，且明确：测试时除股东现金流预测假设外，寿险合同负债假设也可同时更新；依据可操作性原则，最低资本预测因子可不变。公司应呈现不同情景下的调整净资产、有效业务价值和新业务价值。

#情景建议变动EV/VNB 典型变动幅度
1风险贴现率（负债贴现口径之一）± 50bps± 5.0%
2投资收益率± 50bps± 20.0%（敏感度最高）
3死亡率± 10%± 1.0%
4发病率+ 10%± 5.0%（发病率及赔付率口径）
5退保率± 10%± 1.0%
6费用（获取 + 维持）+ 10%± 2.5%
7负债贴现率± 50bps与情景 1 同量级，方向相反
结论必须落到这一句：EV 对投资收益率假设最敏感（50bps → 约 ±20%，是 RDR 同幅波动的 4 倍）→ 合理设定投资收益率假设，对价值评估的公允性、定价的充分性、业务的引导至关重要。
实务注脚：2023 年底上市险企已相应下调投资回报率假设与风险贴现率假设（投资收益率假设普遍降至 4.5% 及以下、RDR 降至 8%~9% 区间），以应对利率下行与利差损风险——这是"敏感性结论 → 监管与市场倒逼假设审慎化"的完整闭环，论述题写上它就是亮点。

06EV ≠ 收购价：论述题标准答案 ★★★

2026 真题原题式提问："上市保险公司的内含价值如何计算？内含价值是否等于收购价？" 这是价值评估篇章最具综合性的大题，答案分两层。

第一层：上市公司 EV 怎么算（点击收起）
EV = 自由盈余 + 要求资本 + 有效业务价值 − 要求资本成本
评估价值 AV（Appraisal Value）= 内含价值 EV + 商誉（Goodwill）
商誉 = 未来新业务价值（未来新业务税后可分配利润的现值，扣除持有要求资本的成本）；实务中常用一年新业务价值 × 乘数因子估计，乘数取决于业务组合、利润边际、行业增长、市场份额、竞争地位、偿付能力资本与资本支出等。上市公司还须公开披露经外部审阅的 EV 报告（方法假设 + 结果 + 分析 + 敏感性测试，第五十条）。

6.1 五大差异原因（答题骨架）

  1. 未来新业务：EV 明确不含未来新业务价值（第十一条）；并购通常以评估价值（EV + 商誉）为起点——收购方为持续经营的新业务能力付费。
  2. 控制权溢价：收购取得控制权，交易价格通常包含控制权溢价；EV 只是股东利益现值的审慎计量。
  3. 流动性差异：EV 是持续经营假设下的账面精算价值，非可变现的市场交易价格；股价/成交价还包含流动性与市场情绪因素。
  4. 假设差异：EV 基于当前假设集合（最佳估计 + 特定 RDR），且"内含价值不是衡量公司价值的唯一方法"（第九条）；收购方会用自身资本成本、自身对投资收益/退保/费用的假设重估。
  5. 市场环境：EV 受经济与经营环境影响（利率下行时 EV 下调）；实际成交价受谈判、交易结构（如多次成交价格调整条款）等影响，可能产生较大偏差。
一句话收官EV 是"存量业务 + 净资产"的精算价值底线；
收购价 ≈ EV + 未来新业务价值（商誉）+ 控制权溢价 ± 流动性/假设/谈判调整；
二者通常不相等，收购价一般高于 EV。

6.2 EV 相对其他指标的优势（比较题备用）

口径假设风格出发点局限
法定会计 SAP保守、收付实现制监管偿付能力只承认已实现收入和已发生费用，低估当期价值
一般会计 GAAP权责发生制、贴近实际利润确认的合理性不直接回答"公司值多少钱"
EV / VNB经济口径、未来现金流 + 风险股东价值的现值依赖假设；时点值需靠 EV 桥判断质量

07TEV vs MCEV · 演进与应用 ★★

7.1 中国 EV 体系建设时间线

20 世纪 60~70 年代英国多起针对寿险公司的恶意收购——寿险利润的延迟性、预期性使会计报表只反映部分利润，公司价值被系统性低估。
1984 年英国寿险公司率先将 EV 用于市值管理，解决估值不合理带来的恶意收购问题；随后经跨国公司业务推广至世界各地。
2005 年原保监会发布《人身保险内含价值报告编制指引》——国内首次建立统一价值评价标准，引导行业从"唯保费论"转向价值创造。
2008 年欧洲保险 CFO 论坛发布市场一致内含价值 MCEV 原则。
2016 年废止指引（简政放权），授权中国精算师协会发布现行《精算实践标准：人身保险内含价值评估标准》——基于偿二代一期优化：负债评估与资本预测同偿二代衔接；引入剩余边际平滑股东可分配盈余；允许载体法预测最低资本。
2022.10 起金融监管总局人身险司指导下，中国精算师协会启动标准修订（2023 年 8 月、11 月两轮内部测试）；方向：与 IFRS17 利润边际（CSM + 风险调整）的勾稽、MCEV 适用性、管理精细化。

7.2 TEV vs MCEV（折叠背诵版）

展开六大维度对照（现行标准 = TEV）
维度TEV（传统，中国现行）MCEV（市场一致）
总体方法确定性方法保障型确定性；含选择权/保证产品用风险中性随机模拟
投资收益假设基于资产配置和预期资产收益无风险利率和市场一致定价
运营假设最佳估计动态退保、保单持有人行为、公司管理行为
选择权和保证成本隐含在 RDR 中随机模拟计算 TVOG
贴现率单一百分数 = 无风险利率 + 风险边际无风险利率曲线和市场一致定价
资本成本RDR > 投资收益率时计持有要求资本的息差损无息差损，但考虑摩擦成本和不可对冲风险成本

一句话判断：国内金融衍生品市场和定价工具尚不成熟，当前采用 TEV 方法可靠性更高——这也是简答题"为什么中国不用 MCEV"的标准答法。

7.3 管理应用五场景 + VNB 驱动四因素

  • 战略/资本决策：增资、引战及并购（评估价值 = EV + 商誉）；
  • 产品定价与业务引导：产品利润测试、新业务价值率（VNB / 新单保费）考核；
  • 资本管理：偿付能力、资本注入与分红决策参考；
  • 绩效考核：EV 营运利润 = 当期 VNB + 上期末有效业务利润期望收益 ± 经验和假设差异（EV 利润再含投资收益偏差、自由盈余投资收益、经济假设变化）；
  • 信息披露：财报补充披露 EV、VNB。

VNB 内部管理四大驱动因素：规模及结构（保费、人力、渠道/产品结构）、业务成本（费用、佣金、津贴）、业务品质（继续率、赔付率、退保率）、投资能力（投资收益率、资产负债匹配）。2026 真题"如何提升新业务价值"一题的答题框架即由此展开（详见 真题馆）。

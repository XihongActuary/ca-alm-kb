00总路线图：一道真题就是一条流水线

偿二代计算题（尤其 Excel 操作题）本质是一条流水线，任何题目都是在这条线上「填空」：

① 认可资产 —— 逐项资产 × 认可比例（次级债按剩余期限折扣、权益按市值、投资性房地产按成本模式）。
② 认可负债 —— 寿险合同负债（最优估计 + 风险边际）+ 现金价值保证 + 所得税准备；剔除资本性负债。
③ 实际资本 = ① − ② —— 按「吸收损失能力」切四级（保单未来盈余按剩余期限分档）。
④ 最低资本 —— 保险风险（情景法/因子法）+ 市场风险 + 信用风险 → 相关性矩阵汇总 − LA + 控制风险 + 附加。
⑤ 两率与判定 —— 核心 = 核心资本/MC ≥50%；综合 = AC/MC ≥100%；对照监管措施分层。

本专章知识来源：偿二代二期《保险公司偿付能力监管规则》第 1 号（实际资本·评估原则）、第 2 号（最低资本·风险因子）、第 3 号（寿险合同负债）、第 4~7 号（各风险最低资本细则）＋ 金规〔2023〕5 号（因子与盈余限额调整）。本章所有因子表均以现行规则为准，规则更新时以当期为准。徽章：规 = 监管规则原文、题 = 历年真题。

核心问题自测（先把流水线背下来，再展开对照）

认可资产三门槛与"三加两减"是什么？

三门槛：处置不受限制、不在非认可清单、按认可标准计量。三加两减（认可资产 = 会计资产 + 例外认可项目 − 非认可项目 − 处置受限调整）：加投资性房地产（成本模式）、对子公司长期股权投资（权益法）、寿险应收分保准备金；减无形资产（土地使用权除外）与经营性亏损递延所得税资产、待摊费用等非认可项、减被质押冻结等处置受限部分。

次级债折扣表与保单未来盈余分档？

次级债（无赎回）按剩余期限：≥5 年 100%、4~5 年 80%、3~4 年 60%、2~3 年 40%、1~2 年 20%、<1 年 0；有赎回条款按赎回日剩余期限分档且利差超 100bps 部分不认可。保单未来盈余：≥30 年核心一级、10~30 年核心二级、5~10 年附属一级、<5 年附属二级。

寿险主要风险因子速记？

死亡 +15%、疾病 +20%、维持费用 +10%、退保 ±30%（含期缴）/±40%（趸交）、大规模退保 +150%（月 ≥2.4% 或年 ≥25%）；沪深 300 成份股 0.30（金规 5 号后）、创业板 0.45、科创板 0.40；再保境外分入人：有担保 0.077 / 无担保 0.499 / 不达标 0.867。

相关性矩阵的关键数字？

利率—权益 ρ = −0.14；人身险市场—信用 ρ = 0.35、寿险—市场 0.30（其余详见 CH.02 表）；H 公式中市场与信用按 ρ = 0.25 汇总：8%×√(MC市场² + 2×0.25×MC市场×MC信用 + MC信用²)。

01第一站：认可资产与认可负债

1.1 资产逐项认可 ★★★

资产认可口径坑点
债券/股票/基金公允价值（市值）处置受限（质押/冻结）→ 非认可
投资性房地产成本模式计量不能用公允价值模式
对子公司长期股权投资权益法市场风险中对保险类子公司因子 0.35、一般子公司 1.0
无形资产不认可（土地使用权除外）高频选择题
次级债/资本补充债（持有的）按市场价值与信用风险计量与「发行的」折扣表区分开
应收分保准备金按规则第 3 号确认（分保前后负债差额）分保前负债全额确认为认可负债

1.2 负债逐项认可 ★★★

寿险合同负债（规则第 3 号）
认可负债 = 未到期责任准备金（最优估计 PV+TVOG + 风险边际 RM）+ 未决赔款准备金（账面价值）
RM = MC分保前保险风险 × Φ⁻¹(85%) / Φ⁻¹(99.5%)
折现率曲线 = 750日均线(≤20y) + 二次插值(20~40y) + 终极4.5%(>40y) + 综合溢价(75/45/30BP)
三笔「加项」负债别漏：① 现金价值保证 CVG = Max(CV − PL − MC, 0)；② 所得税准备（以剩余边际为基础，趋势根本逆转才可终止确认）；③ 超资本限额的资本工具部分（确认为资本性负债）。两笔「减项」：农险大灾风险保费准备金、符合资本标准的长期债务（它们已按资本计量，不能重复扣）。

2.1 发行的资本工具：折扣与定级 ★★★

工具级别认可价值（剩余期限 r）
普通股 / 留存利润核心一级全额
无固定期限资本债券（永续）核心二级全额（无到期或 ≥10 年、含减记/转股、发行 5 年后可赎回、无利率跳升激励）

资本补充债（有赎回条款）视期限r≥4年全额；3~4年 80%；2~3年 60%；1~2年 40%；<1年 20%

资本限额四数附属 ≤ 核心 100%；核心二级 ≤ 30%；附属二级 ≤ 25%；盈余入核心 ≤ 35%（10年以上 40%，金规5号）。

2.2 保单未来盈余近似式 ★★

保单未来盈余 = 寿险合同负债账面价值 − 偿付能力口径认可价值 − 现金价值保证 − 所得税准备
整体为负 → 直接调减核心一级。这道式子是「会计 vs 偿报」两张报表的桥梁，简答论述常考其经济含义：监管只允许「足够长久」的未来利润充当吸收损失的资本。

偿付能力演算器 规则Ⅱ口径

核心偿付能力充足率 = 核心资本 / 最低资本（≥50%）80.0%　
综合偿付能力充足率 = 实际资本 / 最低资本（≥100%）133.3%　
注意：核心资本 = 核心一级 + 核心二级（受限额约束后）；风险综合评级 ≥B 类为第三项达标条件，此处未输入。
用演算器体会三件事：① 认可负债每 +1 亿，综合充足率约降 6~7 个点（以默认值计）——这就是「折现率曲线下移 → 负债 ↑ → 充足率 ↓」的量化直觉；② 核心与综合的差距 = 附属资本厚度；③ 两率的分母都是 MC——降 MC（如再保、对冲、金规5号因子优化）与增资本同样有效。

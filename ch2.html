01导语：一张资产负债表的三套语言

同一家保险公司，资产负债表要「说三套语言」：会计准则（通用目的，IFRS17/CAS25）、偿付能力监管（保单持有人保护目的，规则Ⅱ）、内含价值（股东视角，EV 标准）。科目八考的正是第二套语言——以及它和另外两套的翻译关系。

这套语言的骨架只有两句话：

实际资本 AC = 认可资产 − 认可负债　　（你有多少家底）
最低资本 MC = 可资本化风险 + 控制风险 + 附加资本　　（监管要求你备多少）
综合偿付能力充足率 = AC / MC ≥ 100%　　核心充足率 = 核心资本 / MC ≥ 50%
2026 年真题「利率变化对实际资本、保险/市场/信用风险最低资本的影响」「再保险对实际资本与最低资本的影响」都是围绕这三行公式展开——每一道简答题都是问「某个冲击沿着这条公式链怎么传导」。

本章讲框架与关键数字，逐条计算演示在专章 A 偿二代计算手册，利率情景与压力测试细节在专章 B。三页配合食用。

2.1 偿付能力达标三条件与"必须同时采取"的四项监管措施？

三条件：核心充足率 ≥50%、综合充足率 ≥100%、风险综合评级 ≥B 类。核心 <50% 或综合 <100% 时监管必须同时采取：监管谈话、要求提交风险管理计划、限制董监高薪酬、限制向股东分红；可追加责令增资、停新业务、限制投资等形式。重点关注线：核心 <60% 或综合 <120%。

2.2 实际资本的定义、认可资产三门槛、次级债折扣公式？

实际资本 = 认可资产 − 认可负债。认可资产三门槛：处置不受限制、不在非认可清单、按认可标准计量。次级债（无赎回条款）认可价值 = MIN{发行确认价值 − MAX(0, 账面价值 − 认可价值) − 已摊销发行费用, 折扣后上限}；折扣按剩余期限：≥5 年 100%、4~5 年 80%、3~4 年 60%、2~3 年 40%、1~2 年 20%、<1 年 0。

2.3 资本五特性、四级名称与排序、保单未来盈余分档？

五特性：存在性、永续性、次级性、非强制性、外生性。四级（吸收损失能力由强到弱）：核心一级 > 核心二级 > 附属一级 > 附属二级。保单未来盈余按剩余期限分档：≥30 年核心一级、10~30 年核心二级、5~10 年附属一级、<5 年附属二级；盈余计入核心一级 + 二级合计 ≤核心一级的 35%（金规 5 号由 35% 调整口径）。

2.4 最低资本构成公式与三大可资本化风险的定义？

最低资本 = 可资本化风险（保险风险 + 市场风险 + 信用风险，经相关性矩阵汇总）+ 控制风险 + 附加资本。保险风险：赔付 / 给付等承保结果的不利偏差；市场风险：利率 / 权益 / 房地产 / 汇率等市场价格的不利变动；信用风险：利差风险（交易对手违约导致价格下降）+ 交易对手违约风险本体。

2.5 折现率三段曲线与综合溢价三档？

三段：≤20 年取 750 个交易日移动平均国债收益率曲线；20~40 年用二次插值平滑过渡；>40 年用终极利率 4.5%。综合溢价：基础利率曲线 ≤上限时，人身险基础利率上限之上分别加 75bps / 45bps / 30bps（三档）——溢价越高，负债评估越审慎。

2.6 压力测试的法定情景与资本管理的工具箱？

综合压力测试情景：利率上升 / 下降、权益价格下跌、房地产价格下跌、汇率不利变动及其组合。资本工具箱：核心一级（留存利润、增资、保单未来盈余 ≥30 年档）、核心二级、附属一级（次级可转债）、附属二级（资本补充债 / 次级债）、再保险、衍生品对冲。金规〔2023〕5 号：沪深 300 因子 0.35→0.30、盈余计入核心比例调整等差异化措施。

03星级讲义

本章知识来源：偿二代二期《保险公司偿付能力监管规则（1~20 号）》（核心：第 1 号评估原则、第 2 号实际资本与最低资本、第 3 号寿险合同负债、第 4~7 号风险最低资本）＋ 银保监会令 2021 年第 1 号《保险公司偿付能力管理规定》＋ 金规〔2023〕5 号差异化监管通知。徽章：规 = 监管规则原文、题 = 历年真题、教 = 指定教材。全站来源地图见 首页 · 教材与制度地图。

2.1 监管框架与达标线 ★★★规

三支柱（银保监会令 2021 年第 1 号《保险公司偿付能力管理规定》）：定量资本要求（第一支柱）+ 定性监管要求（第二支柱）+ 市场约束机制（第三支柱）。

达标三条件（缺一不可）：

核心偿付能力充足率 ≥ 50% —— 核心资本 / 最低资本
综合偿付能力充足率 ≥ 100% —— 实际资本 / 最低资本
风险综合评级 ≥ B 类 —— 评价操作/战略/声誉/流动性等难以资本化风险
分层监管措施（第 26 条，高频）：核心 <50% 或综合 <100% 时，监管必须同时采取四项：① 监管谈话；② 要求提交预防恶化/完善风险管理计划；③ 限制董监高薪酬；④ 限制向股东分红。视原因可追加：责令增资、停止部分或全部新业务、限制投资形式或比例、调整资产结构等。仍未改善 → 接管、申请破产。另记两个「重点关注线」：核心 <60% 或综合 <120% 属重点核查对象。

2.2 实际资本：认可资产与认可负债 ★★★规题

评估四原则（规则第 1 号第 5 条）：以母公司财务报表为基础；资产负债评估原则一致；同业务同原则；会计准则基础上按监管目的调整。

模块要点考点提示
非认可资产无形资产（土地使用权除外）、经营亏损递延所得税资产、待摊费用、处置受限资产、文物艺术品等选择题常客：土地使用权可以认可
例外认可投资性房地产按成本模式；对子公司长投按权益法；寿险应收分保准备金按第 3 号确认「成本模式」三字是采分点
非认可负债农险大灾风险保费准备金；符合资本标准、用于补充实际资本的长期债务（次级债、资本补充债、次级可转债）逻辑：它们是资本而非负债，不能两边都算
现金价值保证CVG = Max(寿险现金价值 − 合同负债认可价值 − MC, 0)；负债+MC ≥ 现金价值则不确认保护退保高峰的或有义务
所得税准备应纳税所得额预期持续为正时，以寿险合同负债剩余边际为基础确认；确认后仅趋势根本逆转方可终止衔接会计剩余边际概念
次级债 / 资本补充债认可价值折扣（第 25、26 条）——2026 真题「债权认可价值」直接命中
无赎回条款（含次级可转债）：剩余期限 ≥2年 → 100% 认可；1~2年 → 50%；<1年 → 80%
有赎回条款：≥4年 → 100%；3~4年 → 80%；2~3年 → 60%；1~2年 → 40%；<1年 → 20%
注意：折扣对象是「计入实际资本的部分」随剩余期限递减；赎回判定——赎回日前后票面利率差超 100BP 或有提前赎回证据 → 剩余期限按赎回日计。记忆：越临近到期/赎回，资本属性越弱，计入越少。

2.3 资本四级分级与保单未来盈余 ★★★规

资本五特性（第 28 条）：存在性（实缴）、永续性、次级性、非强制性、外生性——判断任何资本工具级别的万能尺子。

核心一级股本等 · 吸收损失能力最强
核心二级无到期或≥10年 · 含减记/转股
附属一级期限≥5年 · 仅清算时吸收
附属二级期限可低于5年 · 约束最少
受偿顺序（由后到先）：核心一级 → 核心二级 → 附属一级 → 附属二级 → 保单持有人与一般债权人。级别越低，吸收损失能力越强、监管标准越严。

保单未来盈余分级计入（第 35–37 条）——偿二代二期最重要的「中国特色」设计：

剩余期限计入级别
≥ 30 年核心一级（按核心一级资本报酬率折现）+ 剩余部分附属一级
10 ~ 30 年核心二级 + 剩余附属一级
5 ~ 10 年附属一级 + 剩余附属二级
< 5 年全部附属二级

近似公式：保单未来盈余 = 财务报表寿险合同负债账面价值 − 偿付能力口径认可价值 − 现金价值保证 − 所得税准备；整体未来盈余为负则直接调减核心一级资本。

资本限额（第 41 条 + 金规〔2023〕5 号）——必背四数附属不超核心整（100%），核心二级三成整（30%）；
附属二级两成半（25%），未来盈余三五并四成（35%→40%）。
超限部分转性负债，不再充作资本数。

2.4 最低资本：三大可资本化风险 ★★★规题

风险框架：偿付能力风险 = 固有风险 + 控制风险；固有风险 = 可资本化风险（保险/市场/信用，VaR 法）+ 难以资本化风险（操作/战略/声誉/流动性，进风险综合评级）；控制风险按 SARMRA 评估结果计量（监管评价法）。

最低资本总公式与相关性汇总（第 2 号第 5、15 条）
MC = 可资本化风险 MC* + 控制风险 MC + 附加资本（逆周期附加、系统重要性附加等）
MC* = √(MC向量 · ρ矩阵 · MC向量ᵀ) − LA（分红万能损失吸收效应）
LA = Min(MC分红万能账户 × β, LA上限)——分红/万能账户的浮动收益机制天然吸收市场与信用冲击，监管允许扣减。β = (1+K) × Min(0.5, 0.22×LA上限/MC账户 + 0.02)。

三大风险要点速览（完整因子表见专章 A）：

风险子风险计量方法与关键数字
保险风险
（第 4/5 号）		寿险：损失发生 + 费用 + 退保情景法 MC = Max(PV不利 − PV基础, 0)；死亡 SF +15%、巨灾 +0.0018、疾病 +20%、维持费用 +10%、退保 ±30%/±40%、大规模退保 +150%（月退保率≥2.4% 或年≥25%）；MC退保 = Max(退保率, 大规模退保)
非寿险：保费及准备金 + 巨灾综合因子法 MC = EX×RF0×(1+K)；RF0 如车险 0.103/0.123、财产险 0.391/0.561（保费/准备金）；巨灾仅车险与财产险计提，VaR 置信度 99.5%；ρ(保费及准备金, 巨灾)=0.25
特征系数 K综合成本率 ≤95% → −0.05、>105% → +0.1；回溯偏差率大 → 加分；K ∈ [−0.25, 0.25]
市场风险
（第 8 号）		利率/权益/房地产/境外/汇率/集中度综合因子法 MC = EX×RF0×(1+K)；沪深主板股票 0.35（金规5号后沪深300成份股 0.30）、创业板/科创板 0.45（科创板后 0.40）、物业房地产 0.15、美元汇率 0.05
人身险利率风险 = 情景法MC利率 = Max[PV(NCF)不利 − PV(NCF)基础, 0]——资产负债同时折现的久期缺口思路（2026 真题第 6 题的出题根基）
信用风险
（第 9 号）		利差 + 交易对手违约（+集中度）利差因子按评级 × 修正久期（AAA 至 BBB 递增）；政府债券与央票不计提；评级「多家机构从低适用」
再保险交易对手（2026 真题）境内分入人按综合偿付能力充足率分档（≥200% → 0.008 … <50% → 0.745）；境外分入人（直保分出）：有担保 0.077 / 无担保 0.499，不达标 0.867
相关系数矩阵 · 人身险公司（第 17 条）——计算题给出则必用
MC向量 = (寿险保险, 非寿险保险, 市场, 信用)
ρ：寿险-非寿险 0.20 · 寿险-市场 0.30 · 寿险-信用 0.15 · 非寿险-市场 0.10 · 非寿险-信用 0.10 · 市场-信用 0.35
市场风险内部：利率-权益 ρ = −0.14（负相关！利率上行 → 债券跌 + 股票通常也承压，但组合层面存在分散效应）；信用风险内部：利差-交易对手 ρ = 0.25。

2.5 寿险合同负债评估 ★★规

规则第 3 号的核心一条线：

负债评估公式链
寿险合同负债 = 未到期责任准备金 + 未决赔款准备金（按账面价值认可）
未到期责任准备金 = 最优估计准备金 + 风险边际 RM
最优估计 = 现金流现值 PV + 选择权及保证利益时间价值 TVOG
RM = MC × Φ⁻¹(85%) / Φ⁻¹(99.5%)（分位点法，85% 分位）
万能险：保险与投资部分合并评估不拆分；投连险：独立账户负债 = 独立账户资产市值；分保前负债确认为认可负债，分保前后差额形成应收分保准备金（认可资产）——这行字就是 2026 Excel 再保险题的负债侧钥匙。

折现率曲线（附件 1）——必背图形：

评估折现率曲线 = 基础利率曲线 + 综合溢价
第一段 0<t≤20年：750 日移动平均国债收益率曲线（市场化锚）
第二段 20<t≤40年：终极利率二次插值过渡曲线
第三段 t>40年：终极利率 4.5%（综合溢价归零）
综合溢价：1999 年（含）前高利率保单 75BP · 万能/投连/变额/中短存续期 30BP · 其他 45BP
设计逻辑：750 日均线平滑短期波动（防止利润表随利率上蹿下跳），40 年以上以 4.5% 终极利率托底（长端数据不足）。三段曲线同时是人身险利率风险情景法的评估曲线（第 8 号第 19 条）。
常用假设数字：费用假设——自身经验 ≤105% 可用自身假设，否则用监管下限，物价假设下限每年 2%；TVOG 因子随保证利率升档（0~1% → 16bp 至 >3.5% → 100bp，单位万分之一）；分红下限——36 个月内不低于演示中低档且 ≥0、当年不低于上年 80%；万能结算利率与投资收益率利差 ≤ min(投资收益率假设×25%, 150BP)。

2.6 压力测试与资本管理 ★★规

偿付能力压力测试考察利率、权益、信用等因子同时恶化的极端情景下两率的表现；公司须按三年滚动资本规划（董事会批准）管理资本。资本补充工具箱与各自级别：

工具补充层级要点
普通股增资 / 留存利润核心一级吸收损失能力最强，但门槛高

05真题印证

2026·简2「计算债权认可价值；如何才能计入实际资本？」——考次级债/资本补充债剩余期限折扣表（2.2）+ 资本五特性与分级标准（2.3）。答案骨架：先判有无赎回条款 → 套折扣表算认可价值 → 按期限与条款定级别（≥5年附属一级等）→ 受资本限额约束。
2026·简6「利率变化对实际资本、保险/市场/信用风险最低资本的影响」——本题是本章「公式链思维」的极致体现：利率下行 → 认可负债（折现率曲线整体下移）增、实际资本承压；市场风险中人身险利率风险用情景法，资产与负债同时折现、久期缺口决定方向；信用风险经利差与债券估值间接传导；保险风险基本不受利率影响（但退保率假设可能联动）。完整答案见真题馆。
2026·Excel3「再保险对实际资本/最低资本的影响、属于哪一层级」——负债侧：分保前后差额 → 应收分保准备金（认可资产）；实际资本侧：长期寿险再保险按第 1 号第 38 条分级（3 年内可终止不得确认）；最低资本侧：分出降低保险风险 MC，但新增信用风险（境内分入人按充足率分档 0.008~0.745、境外有担保 0.077/无担保 0.499），且分出人减少与分入人增加的 MC 原则上一致。
2017·6「偿二代编报规则：保险风险定义、几类、最低资本怎么算；信用风险、利差与交易对手风险、哪些资产计交易对手风险」——就是本章 2.4 的原样默写题，足见「框架题」十年不衰。
2013·19「预测偿付能力、如何通过 ALM 改善」——把本章与 CH.04 串起来的经典问法：改善路径 = 资产端（拉长久期/降波动）、负债端（调结构/调定价）、资本端（增资/发债/再保）三管齐下。
完整作答示范：2017·6「保险风险定义、构成与最低资本算法；信用风险、利差与交易对手风险及适用资产」

一、保险风险：指由于死亡率、疾病发生率、赔付率、退保率、费用假设等承保相关因素的不利变动，导致公司遭受非预期损失的风险。对人身险公司包括：死亡伤残风险、疾病医疗风险、长寿风险、费用风险、退保风险、大规模退保风险等；对非寿险公司包括：保费及准备金风险（含巨灾）、承保结构风险等。最低资本 = Σ（风险暴露 EX × 基础因子 RF0 × 特征系数 k）。以寿险死亡风险为例：EX 为有效保额（净额，扣再保摊回），冲击为死亡发生率 +15%；退保风险按退保率 ±30%（含期缴）/ ±40%（趸交）双向冲击取不利者。

二、信用风险：指由于利差的不利变动或交易对手违约（评级下调 / 恢复率变化），导致公司遭受非预期损失的风险。分两类——① 利差风险：债券等固定收益资产因信用利差走阔而价格下跌的风险，最低资本 = EX（持仓市值）× RF0（由修正久期与外部评级共同决定，久期越长、评级越低因子越大）；② 交易对手违约风险：交易对手不能履约导致表内外资产损失的风险。

三、哪些资产需要计算交易对手违约风险：① 应收分保账款（含账龄调整因子：≤6 个月最低、>12 个月更高）；② 银行存款与存单（按银行评级与期限）；③ 再保险分入人的信用敞口——境内分入人按其综合偿付能力充足率分档（≥200% 因子仅 0.008，<50% 高至 0.745），境外分入人有担保 0.077 / 无担保 0.499 / 不达标 0.867，多个分入人无法合理拆分时按最差者适用；④ 结构化主体与表外担保等或有敞口。

答题提示：本题是"定义 + 构成 + 公式 + 适用范围"四件套默写题——2026 年简 6 与 Excel 3 是它的现代化身（改成考"利率如何影响这三大风险"与"再保险对三风险的方向"），框架没变，考法在升级。

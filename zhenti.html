简 1 · 结合资产负债管理，优化战略资产配置（SAA）

题目还原：回顾资产负债管理（ALM），论述如何优化 SAA（战略资产配置）。

参考答案（点击展开）

第一层 · 定位：SAA 是长期、政策层面的资产配置决策（大类资产目标比例与再平衡区间），TAA 在其框架内做战术偏离。ALM 优化的本质是把负债特性写进 SAA 的约束条件和目标函数——资产配置不是收益率的单目标优化，而是"收益 − 风险 − 负债匹配"的多目标优化。

第二层 · 约束条件（ALM 视角）：① 期限结构约束：规模调整后的久期缺口控制在评分友好区间（±2 年内，专章 B），负债久期长的账户配长久期利率债；② 成本收益约束：G − K ≥ 0（综合收益率覆盖资金成本率），按账户分别校验；③ 流动性约束：流动性比例 ≥5%、现金流测试三级检验通过；④ 偿付能力约束：各类资产风险因子（权益 0.35/0.30、利差按久期与评级）占用最低资本，SAA 要算资本效率（H = RAROI，专章 B）。

第三层 · 流程与方法：账户划分（普通账户分传统/分红/万能子账户 + 独立账户）→ 分账户负债特性分析（久期、现金流形态、保证成本）→ 情景与压力测试（六利率情景 + 成本收益四情景）→ 生成有效前沿（以 H 或风险调整收益为目标）→ 董事会审定，每年至少滚动评估一次（规则第 5 号）。

第四层 · 落点（2026 语境）：低利率下 SAA 优化的现实方向——拉长固收久期、控制权益与高波动资产比例、用分红万能的浮动机制换取资产端灵活性、资本占用低的高评级债券优先（专章 D）。

考点回链：CH.04 §SAA/TAA · 专章 B 权重体系 · 专章 D 低利率

详尽版答案（考试满分长度 · 展开 1500 字论述）

一、定位与逻辑起点（约 3 分）。资产负债管理是在风险偏好约束下，对资产端与负债端进行协同管理、实现财务安全性与盈利性动态平衡的技术与制度安排。SAA（战略资产配置）是资产端最重要的长期决策——它决定大类资产的长期目标比例与再平衡区间，贡献组合 90% 以上的长期风险收益特征。传统 SAA 以"收益—风险"二维优化为目标，而 ALM 视角的 SAA 优化必须把负债特性内生化为约束条件与目标函数：即从"资产端单目标优化"升级为"资产负债联合多目标优化"。这是本题的立意所在。

二、四大约束条件（约 4 分，每条都要点出指标与规则出处）：

约束监管指标（阈值）规则出处SAA 上的落法
期限结构规模调整后久期缺口（评分友好区间 ±2 年）；利率风险对冲率；基点价值变动率 ≤30% 满分监管规则第 4 号长久期负债账户增配超长期利率债、控制短久期资产占比
成本收益综合收益率 G ≥ 资金成本率 K（M = G−K ≥ 0）；基本情景 19 分 + 压力情景 21 分监管规则第 4 号配置收益可覆盖负债成本的大类资产；高股息、长久期票息资产优先
流动性流动性比例 ≥5%；现金流三级检验无一期为负监管规则第 4 号保留流动性资产梯队（现金、货基、短债、1 年以上政府债）
资本效率各类资产最低资本风险因子占用；H = RAROCI = G−资本成本/NUIF偿二代二期规则第 2 号同样预期收益下选资本占用低的资产（高评级债券、绿色债券 k1=−0.1）

三、优化流程六步（约 3 分）：① 账户划分——普通账户按传统 / 分红 / 万能分子账户，独立账户单列，各账户负债特性不同、约束不同；② 分账户负债分析——久期、关键期限（DV10）、现金流形态、保证成本（预定利率 / 结算利率 / 宣告分红）；③ 情景与压力测试——六种利率压力情景 + 成本收益四大压力情景（尤其情景二长期低利率：再投资收益率按期限下调 24%~73%）；④ 生成有效前沿——以风险调整收益（H 或利差）为目标、上述四类约束为条件求解，得到各账户大类资产目标区间；⑤ 治理审批——董事会审定，每年至少滚动评估一次（监管规则第 5 号）；⑥ 执行与再平衡——TAA 在区间内战术偏离，超限触发再平衡。

四、2026 语境的现实落点（约 2 分）：长期低利率环境下，SAA 优化呈现四个确定性方向——① 拉长固收久期、向负债久期收敛；② 控制权益与高波动资产比例、以高股息替代部分弹性仓位；③ 用分红万能的浮动收益机制换取资产端灵活性（负债端 LA 系数获监管承认）；④ 资本占用低、久期长的超长期国债与地方政府债占比提升。结尾点题：SAA 优化的本质，是把"负债的语言"翻译成"资产的约束"——这正是 ALM 区别于单纯投资管理的根本。

详版答题提示：全文按"定位 → 约束（表格）→ 流程 → 落点"四段展开，每段均需挂一个监管规则编号，是拉开分差的关键。

简 2 · 债权认可价值与实际资本

题目还原：计算债权认可价值；债权如何才能计入实际资本？

参考答案（点击展开）

认可价值计量：偿付能力口径下资产评估以市场价值（公允价值）为基础、与负债评估原则一致、在会计基础上按监管目的调整（规则第 1 号评估原则）。债权类资产（国债、金融债、信用债、非标债权等）：存在活跃市场的按市价；无活跃市场按估值技术（现金流折现，用与期限匹配的市场利率）；已发生减值的扣除减值。Excel 题按题给表格逐笔折现或取市值加总。

计入实际资本的三个门槛：① 认可资产定义——处置不受限制、可用于履行对保单持有人赔付义务（权属清晰、未被冻结/质押/抵押、不受境外管制等处置受限情形）；② 不在非认可清单——无形资产（土地使用权除外）、经营性亏损递延所得税资产、待摊费用、文物艺术品等不得认可；③ 按认可标准计量后进入认可资产，实际资本 = 认可资产 − 认可负债。

易错点：为他人担保被质押的债券、交易对手出现危机期间的相关资产 → 处置受限 → 不可认可；以物权/项目公司方式持有的投资性房地产是例外认可（成本模式），别和债权混淆。

考点回链：CH.02 认可资产负债 · 专章 A 认可资产逐项表

详尽版答案（含示例计算表 · 认可价值怎么"算"出来）

一、认可价值计量的四条原则（规则第 1 号·评估原则）：① 以市场价值（公允价值）为基础；② 资产评估与负债评估原则保持一致（同一套利率曲线）；③ 在会计计量基础上按监管目的进行调整（认可 ≠ 账面）；④ 存在活跃市场的取市价，不存在活跃市场的用估值技术（现金流折现，折现率取与剩余期限匹配的市场利率），已发生减值的资产以扣除减值后的金额认可。

二、债权类资产的分类计量（示例：一笔 3 年期信用债）：

项目示例数据计量处理
面值 / 票息10 亿元 / 3.5%年利息 0.35 亿元
期限结构折现率（同评级同期限）1 年 2.8% / 2 年 2.9% / 3 年 3.0%无活跃市价 → 估值技术折现
各期现值0.34 + 0.33 + 9.510.35/1.028 + 0.35/1.029² + 10.35/1.03³
认可价值10.18 亿元无减值、无处置受限 → 全额认可

若该债券已计提减值 0.5 亿元，认可价值 = 10.18 − 0.5 = 9.68 亿元；若被质押（为他人担保），处置受限 → 非认可（0）。

三、计入实际资本的完整链条（分三问作答）：第一问"是什么"——认可资产须满足：权属清晰、处置不受限制、可用于履行对保单持有人的赔付义务；第二问"不是什么"——无形资产（土地使用权除外）、经营性亏损递延所得税资产、待摊费用、文物艺术品等属非认可；第三问"怎么进"——按认可标准计量后计入认可资产，实际资本 = 认可资产 − 认可负债，债权通过"资产端全额认可"进入实际资本，而非作为资本工具分级（注意与次级债的区别：次级债是负债端的非认可处理从而留存实际资本，本题债权是资产端的认可计量——两条路径完全不同，混为一谈是本题最常见失分点）。

详版答题提示：三问结构（是什么 / 不是什么 / 怎么进）+ 一个带数字的示例，比纯文字答案多拿 2~3 分。

简 3 · 上市公司 EV 计算与收购价

题目还原：上市保险公司的内含价值如何计算？内含价值是否等于收购价？

参考答案（点击展开）

计算层：EV = 自由盈余 FS + 要求资本 RC + 有效业务价值 VIF − 要求资本成本 CoC（标准第十、十一条）。上市公司须披露经外部审阅的 EV 报告（方法假设 + 结果 + 分析 + 敏感性测试）。各分项定义与精细公式见 专章 C 第一节——答题时四要素每个都要一句话定义。

判断层：不等，收购价一般高于 EV。五大原因：① 未来新业务——EV 明确不含未来新业务价值，并购以评估价值 AV = EV + 商誉为起点，商誉 ≈ 一年 VNB × 乘数；② 控制权溢价；③ 流动性差异——EV 是持续经营账面精算价值，非可变现交易价格；④ 假设差异——收购方用自身资本成本与假设重估，且 EV 不是衡量公司价值的唯一方法（标准第九条）；⑤ 市场环境——利率下行时 EV 下调，成交价还受谈判与交易结构影响，可能产生较大偏差。

收官句：EV 是"存量业务 + 净资产"的精算价值底线；收购价 ≈ EV + 未来新业务价值 + 控制权溢价 ± 流动性 / 假设 / 谈判调整。

考点回链：专章 C §EV vs 收购价（含完整论述题标准答案）· CH.03

详尽版答案（含示例数字 · EV 计算演算表）

一、EV 四要素计算（示例数据演算，标准第十、十一条）：

要素定义一句话示例（亿元）
自由盈余 FS分配给适用业务的净资产中不受任何约束的部分200
要求资本 RC适用业务对应的所有者权益中受到限制、不得分配给股东的部分（监管资本 + 内部限制超出部分）；RC = max{0, MC + max[0, CV−(RES+DPL)]} − DTL100
有效业务价值 VIF有效适用业务及其对应资产未来产生的股东现金流现值（含金融选择权和保证的成本）350
要求资本成本 CoC要求资本在未来不能全部返还给股东造成的价值损失（持有资本的机会成本）−30
内含价值 EVEV = FS + RC + VIF − CoC620

二、上市公司的特殊要求：按《精算实践标准：人身保险内含价值评估》（2016 版，中精协）第五十条，上市公司应披露经外部审阅的内含价值报告，内容至少包括：主要评估方法和假设、计算结果、相关分析、敏感性测试；重要性上限 = EV（或 VNB）总额的 5% 与 1000 万元孰大。评估频率：至少每年一次（评估日 12 月 31 日），假设应与评估日可获取的信息一致。

三、"是否等于收购价"——判断 + 五大原因（每条给机制）：

差异来源机制解释
未来新业务EV 定义明确不包括未来新业务价值；并购定价以评估价值 AV = EV + 商誉为起点，商誉 ≈ 一年 VNB × 乘数（反映新业务的持续创造能力）
控制权溢价取得控制权可整合渠道、品牌、投资平台，收购方愿为控制权支付 EV 之上的溢价
流动性差异EV 是持续经营假设下的精算账面价值，不是可变现的交易价格；股权交易本身有流动性折价 / 溢价
假设差异收购方以自身资本成本与精算假设重估；且标准第九条明示 EV 不是衡量公司价值的唯一方法
市场环境利率下行期 EV 被下调，成交价还受谈判力量、交易结构、监管审批影响，两者可能出现较大偏差

四、收官句（背下来）：EV 是"存量业务 + 净资产"的精算价值底线；收购价 ≈ EV + 未来新业务价值 + 控制权溢价 ± 流动性 / 假设 / 谈判调整，一般高于 EV。两者是"底线"与"成交"的关系，不是同一概念。

详版答题提示：计算层务必写全四要素各自的一句定义；判断层五大原因每个都带机制，不要只列名词。

简 4 · 敏感性分析的情景

题目还原：敏感性分析的情景有哪些？

参考答案（点击展开）

标准附件 3 七大建议情景：① 风险贴现率 ±50bps；② 投资收益率 ±50bps；③ 死亡率 ±10%；④ 发病率 +10%；⑤ 退保率 ±10%；⑥ 费用 +10%；⑦ 负债贴现率 ±50bps。测试时除股东现金流预测假设外，寿险合同负债假设可同时更新；依据可操作性原则，最低资本预测因子可不变。

必须补的两层（拉分关键）：① 敏感度排序——投资收益率 ±50bps → EV 约 ±20%（最敏感，是 RDR 同幅波动的 4 倍）；RDR ±50bps → 约 ±5%；发病率及赔付率 ±10% → 约 ±5%；费用 ±10% → 约 ±2.5%；死亡率 / 退保率 ±10% → 约 ±1%。② 披露要求——呈现不同情景下的调整净资产、有效业务价值和新业务价值三个结果。

简 5 · 成本收益匹配的挑战和机会

题目还原：当前环境下，保险公司成本收益匹配面临的挑战和机会。

参考答案（点击展开）

挑战四条（先给机制再给事实）：① 负债成本刚性——存量高预定利率产品形成刚性负债成本，保证成本率 L（预定利率 / 最低保证利率）锁死，情景二下"负债保证成本率与基本情景相同"；② 资产收益下行——长期低利率情景再投资收益率按期限下调 24%~73%，存量非标到期、优质非标供给减少，再配置压力显著（久期错配缺口约 7 年）；③ 结构性错配——负债久期长于资产久期，新钱收益率下移快于负债成本调整；④ 波动放大——权益与房地产波动（情景一：权益按 99% 置信三年 VaR 下跌、房地产 −20%）冲击当期利差。

简 6 · 利率变化对实际资本与三大风险最低资本的影响

题目还原：利率变化对实际资本、保险风险最低资本、市场风险最低资本、信用风险最低资本的影响。

参考答案（点击展开）

总纲：利率是资产负债表的"总开关"，但传导路径各不相同——实际资本走"负债评估"通道，市场风险走"久期敞口"通道，信用风险走"利差与再投资"通道，保险风险基本免疫。

对象传导路径方向
实际资本750 日移动平均国债收益率曲线下移 → 折现率下行 → 寿险合同负债（认可负债）增提 → 实际资本 = 认可资产 − 认可负债 下降；资产端债券市值上升部分对冲，但负债久期 > 资产久期时净效应为负利率 ↓ → 实际资本 ↓（净）；利率 ↑ 反之

收官：这就是 ALM 的核心命题——利率变化对资产和负债的作用不对称，管理久期缺口（对冲率、DV10 体系）就是在管理这条传导链的强度。

考点回链：CH.02 折现率曲线与三大风险 · 专章 A 演算器（认可负债 +1 亿的充足率冲击）

详尽版答案（四个对象逐一展开 · 含数字示例）

一、实际资本（走"负债评估"通道，间接传导）。机制：偿二代下寿险合同负债按 750 个交易日移动平均国债收益率曲线（≤20 年）+ 二次插值（20~40 年）+ 终极利率 4.5%（>40 年）折现，并加综合溢价（基础利率上限之上 75/45/30bps 三档）。利率下行 → 折现率下移 → 负债增提 → 实际资本 = 认可资产 − 认可负债 下降。对冲项：资产端债券市值上升。净效应取决于久期缺口：数字示例——资产 180 亿、D_A = 6；负债 160 亿、D_L = 10：利率 −50bp 时资产 +5.4 亿、负债 +8.0 亿，实际资本净减约 2.6 亿；若久期缺口收窄至 ±2 年，净损失可控制在 1/4 以内。要点：750 日移动平均本身是"减震器"——市场利率即时波动只渐进传导进负债评估。

二、保险风险最低资本（基本免疫）。因子体系基于死亡 / 疾病 / 退保 / 费用等承保假设的冲击（死亡 +15%、疾病 +20%、退保 ±30%/±40%、大规模退保 +150%），与利率无直接联动。间接通道有二：① 利率下行 → 保单持有人寻求更高收益 → 退保倾向上升（大规模退保情景关注月退保率 ≥2.4% 或年 ≥25%）；② 产品结构随利率环境变化（低利率期保证型产品占比变化）。但总体上间接影响小，考试答"基本不变（间接影响有限）"。

三、市场风险最低资本（走"久期敞口"通道，非线性放大）。利率风险最低资本 = Max(各不利情景下 Sum_DV_X) / 核心资本（超限倍数法）：DV10 按剩余期限超 1 年的资产与负债逐期限计算，六情景（上升 / 下降 / 倾斜上 / 倾斜下 / 扭转上 / 扭转下）取最不利。利率波动加剧或久期缺口扩大 → 敞口放大 → 最低资本上升。与实际资本的镜像关系：利率跳升情景下债券市值大跌（资产端损失），而负债评估因 750 日平滑反应迟钝 → 实际资本与市场风险最低资本可能同时恶化——这就是"利率跳升比利率缓降更危险"的机制。

四、信用风险最低资本（走"利差与再投资"通道，视组合结构）。利差风险敞口 = EX × RF0(D, 评级)，两个变量都可被利率环境改变：① 利率下行 → 资金追逐长久期或更低评级资产 → D 或 RF0 上升；② 利率跳升通常伴随信用利差走阔（流动性挤压）→ RF0 上升。交易对手风险因子取决于对手评级 / 充足率（含再保分入人 0.008~0.867 档位），除非发生评级迁徙，一般不随利率变动。

简 7 · 寿险提升新业务价值 + 财险控制综合成本率

题目还原：寿险公司如何提升新业务价值？财险公司如何控制综合成本率？

参考答案（点击展开）

寿险提升 VNB——按定义拆：VNB = 报告期新单在签单时点的价值（含 CoC、含预期续保）。提升路径四条线：① 规模与结构——提高新业务价值率（VNB / 新单保费）高的保障型、长期期交业务占比，渠道结构向高质量个险与价值银保倾斜；② 业务成本——费用与佣金管控（费用假设 ±10% → VNB 约 ∓2.5%）、"报行合一"压实费用；③ 业务品质——继续率、退保率、发生率管控（退保差直接进 EV 桥的经验偏差项）；④ 投资与资本效率——资产负债匹配降低 RDR 与 CoC，审慎且有支撑的投资假设提升 VNB 的可信度。内部管理的四大驱动因素：规模及结构、业务成本、业务品质、投资能力（专章 C §管理应用）。

财险控制综合成本率——按公式拆：综合成本率 = 赔付率 + 费用率。赔付端：精细化定价与风险筛选（定价因子、NCD）、反欺诈理赔管控、巨灾与大灾风险的再保险安排（摊回赔付）、准备金充足与数据治理；费用端："报行合一"压缩手续费与管理费用、渠道效率优化、规模效应摊薄固定成本。再加承保纪律：对持续亏损险种主动收缩（参考 2025 年财险亏损面 10.5%、经营现金流为负比例 24.4% 的行业背景，专章 D），以及非寿险资金成本率 R = (综合成本 − 已赚保费)/(非寿险准备金 + 净资产) 的监控——综合成本率每高 1 个点，承保利润薄一分。

三、财险控制综合成本率——按公式拆：综合成本率 = 赔付率 + 费用率。赔付端四招：① 精细化定价与风险筛选（定价因子、NCD 随车随人）；② 反欺诈与理赔管控（渗漏治理、智能核赔）；③ 巨灾再保险安排摊回赔付；④ 准备金充足与数据治理（准备金不足会以"后置赔付率"形式反噬）。费用端三招：⑤ "报行合一"压缩手续费；⑥ 渠道效率优化与线上化；⑦ 规模效应摊薄固定成本。再加承保纪律：对持续亏损险种主动收缩——行业背景：2025 年财险亏损面 10.5%、经营现金流为负比例 24.4%，说明承保纪律已经是生存问题而非选择题。

四、把两问连起来（点睛）：寿险 VNB 与财险综合成本率是"价值"的两面——寿险按现值思维（贴现的未来利润），财险按流量思维（当期成本率）；但管理逻辑同构：结构（卖什么）、品质（卖得好不好）、成本（花多少）、投资与资本（钱生钱效率）。非寿险资金成本率 R = (综合成本 − 已赚保费)/(非寿险准备金 + 净资产) 把两者串在一个指标里——综合成本率每高 1 个点，R 上升一分，承保端就在消耗资本。

第四步 · 匹配判断：不能完全匹配——① 规模缺口：两组合合计现值 163.5 对负债 95.95，需先明确资金来源与盈余归属；② 期限缺口：组合 1 在 5 年期仅 15 对负债 20+票息流出；组合 2 在 5 / 10 年零现金流，长期负债完全暴露于再投资风险；③ 形态缺口：负债有票息（多时点流出），资产组合按零息集中到期，逐期现金流形态不同构。建议：以组合 1 为主匹配长期负债 + 组合 2 提供前 3 年流动性，并以久期 / 凸性免疫管理残余缺口（现金流匹配不可行时的标准降级方案）。

2009 前 · 第 2 题：马科维茨模型（协方差矩阵 / 最小方差组合 / 风险容忍度）

题干要点：无风险收益率 R0 = 3%；两个风险资产 E(R1)、E(R2) = 15%；V(R1) = 0.01、V(R2) = 0.04、Cov(R1,R2) = 0.01（回忆版 E(R1) 记为 0.01）。问：① 协方差矩阵及奇异性判断、奇异情形列举；② 两风险资产最小方差组合（自融资组合）一般表达式；③ 风险容忍度 = 0.5 的投资者由三资产构成的有效投资组合。

完整解答（含勘误与全部计算）

勘误：回忆版 E(R1) = 0.01 与"风险资产"设定矛盾（低于无风险利率 3% 却仍有方差，投资者不会持有），且按 0.01 计算出现病态结果；对照后续小问的可解性，应为 E(R1) = 0.10。以下按勘误后数据求解（两种数据的方法完全一致）。

① 协方差矩阵与奇异性：

Σ = [ 0.01　0.01 ; 0.01　0.04 ]　　det(Σ) = 0.01×0.04 − 0.01² = 0.0003 > 0 → 非奇异（正定）

协方差矩阵奇异的情形：① 两资产收益率完全线性相关（ρ = ±1）；② 某资产是其他资产的线性组合（如基金完全复制指数）；③ 存在冗余资产使最优权重解不唯一；④ 因子模型下资产数多于独立因子数（秩亏）。

② 最小方差组合（两风险资产）：

w₁* = (σ₂² − σ₁₂) / (σ₁² + σ₂² − 2σ₁₂) = (0.04 − 0.01) / (0.01 + 0.04 − 0.02) = 0.03/0.03 = 1（100% 投 R1），w₂* = 0
经济含义：R1 方差远小于 R2（0.01 vs 0.04），且 ρ = 0.01/(0.1×0.2) = 0.5 的分散化收益不足以补偿持有 R2 的额外方差 → 最小方差组合退化为单资产。自融资组合：w₂ = 1 − w₁，组合收益 = w₁(R1 − R2) + R2，权重和恒为 1。

③ 含无风险资产的最优组合（风险容忍度 T = 0.5）：先求切点（最优风险）组合 w ∝ Σ⁻¹(μ − r·1)：

Σ⁻¹(μ−r·1) = (1/0.0003) × [0.04×0.07 − 0.01×0.12 ; −0.01×0.07 + 0.01×0.12] = (1/0.0003) × [0.0016; 0.0005] = [5.33; 1.67]
切点组合权重：w₁ = 5.33/7.00 = 76.2%，w₂ = 23.8%；μ_t = 0.762×10% + 0.238×15% = 11.19%，σ_t² = wᵀΣw = 0.0117（σ_t ≈ 10.8%）

效用函数 U = E(R) − σ²/(2T)（T = 风险容忍度，0.5；等价于风险厌恶系数 A = 1/T = 2）下，风险资产总投资比例：

k* = T × (μ_t − r) / σ_t² = 0.5 × 0.0819 / 0.0117 ≈ 3.5（杠杆） → 借入 250% 无风险资产，w₁ = 3.5×76.2% = 266.7%，w₂ = 3.5×23.8% = 83.3%
组合期望收益 ≈ 31.7%、方差 ≈ 0.143。若不允许杠杆（借贷约束），解退化为切点组合本身。风险容忍度越小 → k 越小 → 无风险资产占比越高，这是"风险容忍度"参数的全部含义。

与 ALM 的连接（点睛）：本题的"负债端"就是无风险资产的角色——保险公司资产配置是在负债约束（久期、成本、流动性）下的马科维茨扩展，监管规则第 4 号的成本收益匹配评估（H = RAROCI）本质就是"扣掉资本成本后的夏普比率"。

考点回链：CH.04 §4.7 投资理论补充卡（马科维茨全套公式）

2009 前 · 第 9 题：美元久期 vs 有效久期（以万能险 / 投连为例）

以万能险和投连产品为例，比较美元久期和有效久期作为利率风险计量标准的差异。

参考答案（三层比较）

第一层 · 两个度量本身的差异：① 美元久期（Dollar Duration / DV01 族）= 修正久期 × 价格，衡量利率变动单位时价值变动的绝对金额；优点是资产与负债可以直接相减——净美元久期 = 资产美元久期 − 负债美元久期，就是净资产对利率的敞口金额，天然服务于 ALM 的"一张缺口报表"；缺点是不同规模组合间不可直接比较。② 有效久期 = (PV₋ − PV₊)/(2×PV₀×Δy)，用利率上下平移后重新定价得到——允许现金流随利率内生变化，是含权资产 / 负债的唯一正确度量；修正久期假设现金流固定，对含权产品系统性失真。

第二层 · 产品维度的差异：① 万能险——含退保选择权（利率升 → 退保升 → 负债久期缩短）、结算利率粘性（利率降 → 结算利率难降 → 现金流出刚性）、缴费灵活（追加保费随利率环境变化）：现金流对利率高度敏感，修正久期低估其利率风险，必须用有效久期；其有效久期介于传统险（长）与投连（≈0）之间，且随利率水平变化（期权的"随价而变"）。② 投连产品——单位化负债、资产 = 负债动态相等，投资风险全部由客户承担，公司仅承担费用收入的久期：有效久期 ≈ 0、美元久期也很小；利率风险计量意义不大，风险在市场风险（客户端）与费用现金流。

第三层 · 结论（答题收官）：美元久期回答"敞口有多大（多少钱）"，有效久期回答"敏感度有多真（含权后）"——实务上两者联用：先用有效久期刻画含权负债的真实敏感度，再乘以规模化为美元久期进入资产负债缺口表。监管落点：规则第 4 号的 DV10 体系正是"按关键期限的美元基点价值"，而负债有效久期计算中万能 / 分红的浮动机制（LA 调整、结算利率上下限）就是有效久期思想的监管化。

考点回链：CH.04 §4.1 久期三兄弟 · 专章 B §DV10

2013 · 第 23 题：风险—回报状态计算（方法详解）

题干要点：风险—回报状态计算（原题数据回忆缺失，此处给方法论与标准步骤）。

方法论标准答案

风险—回报状态刻画的是：在不同利率情景下，资产与负债的相对价值状态（资金比率）及其对股东的回报含义。标准四步：① 设定情景集——利率平行移动（如 ±100/±200bps）与非平行情景（倾斜、扭转），加上精算假设（赔付、退保）的组合；② 分别折现——每个情景下用该情景的利率曲线重估资产现值 PV_A 与负债现值 PV_L；③ 计算状态指标——资金比率 FR = PV_A / PV_L、盈余 S = PV_A − PV_L、以及股东回报率 = (投资收益 + 承保利润) / 盈余；④ 判定风险状态——FR < 1 的情景出现概率与深度即为利率风险敞口，S 对利率的敏感度（dS/dy，即缺口久期 × 规模）给出对冲需求。展示形式：情景 × 指标矩阵表，或"风险—回报状态图"（横轴利率情景、纵轴盈余 / 回报，标出盈亏平衡利率点）。该方法的现代监管化身：规则第 4 号六情景压力测试与成本收益匹配压测（21 分）本质就是制度化的风险—回报状态分析。
